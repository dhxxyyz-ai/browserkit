Frequently asked questions

Is the GIF Animation Maker tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Are uploaded images sent to a server?

No. All processing happens entirely in your browser, and uploaded images are never sent to or stored on an external server.

How many images can I use?

There's no hard limit, but more images or a larger output size will take longer to generate. For best performance, we recommend 10 images or fewer and an output size of 640px or less.

Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
