Frequently asked questions

Is the AI Background Removal tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Are uploaded files sent to a server?

The image itself is never sent anywhere. On first run only the AI model file is downloaded, and all background-removal processing happens in your browser.

Why does the first run take longer?

The first run needs to download the AI model file. Once the model is ready, image processing itself happens entirely in your browser.

Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
