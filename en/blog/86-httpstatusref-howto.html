HTTP Status Code Reference: The Complete Guide

July 19, 2026

When testing an API, do you have to search every time you get an unfamiliar status code like "429"? HttpStatusRef is a free online reference for looking up HTTP status codes from the 100s through the 500s. Search in real time by code number or name, or use the 1xx-5xx category filter to focus on just the range you need. Click a card to copy the code number instantly, and all searching happens entirely in your browser.

Key Features

🔍
Live Search
Get instant results whether you search by code number, name, or description.
📂
Category Filter
Pick just the category you need from 1xx through 5xx.
📋
Copy a Code with One Click
Click a card and the status code number is copied to your clipboard instantly.
🔒
Fully Local Processing
Searching happens entirely in your browser and is never sent to a server.

How to Use It

1

Enter a Search Term or Choose a Category

Type the code number (e.g. 404) or name (e.g. Not Found) you're curious about into the search box, or click a 1xx-5xx category button to see just that range.

2

Check Results and Copy a Code

Search and filter results are shown as a list of cards. Click the card for the code you want, and the code number is copied to your clipboard right away.

⚠️ Note: This is organized based on the standard HTTP status codes registered with IANA. Non-standard codes used by some frameworks or services may not be included.

What Each Category Means

CategoryMeaning
1xx InformationalThe request was received and processing is continuing
2xx SuccessThe request was processed successfully
3xx RedirectionFurther action (such as moving to another URL) is needed to complete the request
4xx Client ErrorThere's a problem with the request itself that the server can't process
5xx Server ErrorA server-side problem means even a valid request can't be processed

Frequently Asked Questions

Q. Is the HTTP Status Code Reference really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. How many status codes are included?

It provides all 62 codes from 1xx through 5xx, based on the standard HTTP status codes registered with IANA.

Q. How does the search work?

Results filter in real time whether you search by code number (e.g. 404), name (e.g. Not Found), or description.

Q. Is my search query sent to a server?

No. All searching happens within data already stored in your browser, and nothing is sent to an external server.
