Add Line Numbers: The Complete Guide

July 9, 2026

Trying to point out "line 3 has the bug" in a code review or presentation, but the original text has no line numbers so you keep counting by hand? LineNumber is a free online tool for adding line numbers to text or code and copying the result. Freely set the starting number, separator, and digit padding (zero-filling) exactly how you want, and everything happens entirely in your browser, so your text is never sent to an external server.

Key Features

🔢
Set the Starting Number
Set a custom starting number when you want to begin from something other than 1.
✏️
Custom Separator
Choose from 1. , 1: , 1) , or a tab character, or type in whatever separator you want.
🔢
Digit Padding (Zero-Fill)
Pad numbers to a fixed width, filling in leading zeros like 001, 002.
✅
Empty-Line Handling
Choose whether to number empty lines too, or skip them and continue numbering from the next line with content.

How to Use It

1

Enter Text

Type or paste the text or code you want to number into the input box on the left. The numbered text appears live in the result box on the right the instant you type.

2

Set the Starting Number and Digit Padding

Enter the number you want to start from in Starting Number. Enter a value in Digit Padding and leading digits are filled with zeros to that width (e.g., width 3 → 001).

3

Choose a Separator

Click one of the provided separator buttons (. / : / ) / tab), or type your own separator directly into the field on the right.

4

Choose Whether to Number Empty Lines

With the checkbox on (the default), empty lines get numbered too. Turn it off and empty lines stay unnumbered, with numbering continuing from the next line that has content.

5

Copy or Download the Result

Use the 📋 Copy Result button to copy it to your clipboard, or ⬇ Download .txt to save it as a file.

Frequently Asked Questions

Q. Is the Add Line Numbers tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Is what I enter sent to a server?

No. All processing happens entirely in your browser, and what you enter is never sent to or stored on an external server.

Q. Can I change the line number format?

It automatically adds line numbers to your text, making it easy to refer to a specific line during code review or when citing a document.

Q. Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
