Base64 Converter: The Complete Guide

June 20, 2026

When API docs just say "send it Base64-encoded," it can be unclear exactly what that means. Base64Tool is a free online tool for encoding text and images as Base64, or decoding a Base64 string back to its original value. It's commonly used for building API request bodies, inlining images in CSS, or analyzing a JWT token. Everything happens entirely in your browser, so your data is never sent to an external server.

What Is Base64?

Base64 is an encoding scheme that converts binary data (bytes) into ASCII characters. It uses only 64 characters -- 52 upper/lowercase letters, 10 digits, and + and /. It's used to carry binary data through text-only environments, such as email attachments, inline images, and auth tokens.

Example -- Encoding "Hello" as Base64
7JWI64WV7ZWY7IS47JqU

Base64 vs. data URI

FormatCommonly Used In
Base64 only iVBORw0KGgo... API request bodies, JWT, database storage
data URI data:image/png;base64,iVBORw0KGgo... HTML <img src>, CSS background-image, inline email images

Support for Non-ASCII Text

JavaScript's built-in btoa() function can only handle ASCII characters, so entering Korean (or any non-ASCII text) directly throws an error. Base64Tool converts such text to UTF-8 bytes first via encodeURIComponent(), then encodes it as Base64, so it safely handles every Unicode character.

Example -- Encoding "BrowserKit" as Base64
QnJvd3NlcktpdA==
Example -- Encoding non-ASCII text as Base64
67iM65287Jqw7KCA7YK3

Things to Watch For

ItemDetails
Size increaseBase64 is about 33% larger than the original. Inlining large files can affect performance.
Not securityBase64 is not encryption. Anyone can decode it easily, so never use it to hide passwords or sensitive information.
JWT paddingJWT's Base64 encoding omits = padding. If decoding fails, try adding = to the end of the string.
Line breaksSome systems include line breaks (\n) in Base64. Just remove them before decoding.
