Code Minifier: The Complete Guide

July 9, 2026

Sometimes you just want to shave a little off your page load time, but the project is too small to justify setting up a build tool. Minifier is a free online code minifier that strips comments and unnecessary whitespace from HTML, CSS, and JS code. Paste your code and instantly see the minified result and the size reduction -- all processing happens entirely in your browser, so your code is never sent to an external server.

Key Features

📄
Supports HTML, CSS, and JS
Switch tabs to minify each of the three languages. Language-specific rules are applied to each.
🧹
Comment Removal
Removes HTML comments, CSS block comments, and JS line/block comments. Similar-looking patterns inside strings are left untouched.
⚖️
Size Reduction Display
Compares the byte size of the original and the result and shows the reduction as a percentage immediately.
🔒
Fully Local Processing
All minification runs inside your browser. Since your code is never sent to a server, you can safely use it with private code too.

Pick the language of the code you want to minify from the tabs at the top. Switching tabs updates the placeholder text in the input box and applies the rules for that language.

How to Use It

1

Choose a Language Tab

Select whether your code is HTML, CSS, or JS from the tabs at the top.

2

Enter Your Code

Paste the code you want to minify into the input box on the left. The minified code appears in the result box on the right as soon as you type.

3

Adjust the Options

The Remove Comments and Clean Whitespace checkboxes can each be toggled independently. Both are on by default.

4

Check and Save the Result

Check how much smaller the result is than the original in the reduction bar in the middle. Copy it to your clipboard with the 📋 Copy Result button, or save it as a file with the ⬇ Download File button.

Minification Examples

HTML

Original
<!-- comment --> <div class="box"> <p> Hello </p> </div>
Minified
<div class="box"><p> Hello </p></div>
66 bytes→47 bytes(28.8% smaller)

Content inside <pre>, <textarea>, <script>, and <style> tags is excluded from minification and preserved as-is, since whitespace there affects the result.

CSS

Original
/* comment */ .box { color: #333; padding: 10px ; }
Minified
.box{color:#333;padding:10px}

JS

Original
// comment function hello() { var x = 1; return x; }
Minified
function hello() { var x = 1; return x; }

For JS, line breaks are preserved and only the leading/trailing whitespace and comments on each line are removed. Forcibly merging lines could change a script's meaning due to Automatic Semicolon Insertion (ASI) rules, so Minifier keeps the line structure intact for safety.

⚠️ Note: Minifier is a lightweight, regex-based minifier, not a full code parser. It may behave unexpectedly with complex strings or unusual syntax, so always check the minified result before using it. For production deployments, dedicated build tools like Terser (JS), cssnano (CSS), or html-minifier (HTML) are recommended.
