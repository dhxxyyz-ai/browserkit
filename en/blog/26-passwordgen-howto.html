Password Generator: The Complete Guide

June 19, 2026

That news story about an account getting hacked because someone used "abc123" or their birthday as a password probably hits close to home. PasswordGen is a free online tool that instantly generates unpredictable passwords using true random numbers from your browser's Crypto API. Freely set the length and character set (uppercase, lowercase, digits, symbols), and the generated password never leaves your browser.

Key Features

📏
Length Setting (4-64 Characters)
Freely set the password length from 4 to 64 characters with a slider. The current length is shown live.
🔤
Character Set Selection
Turn uppercase, lowercase, digits, and symbols on or off individually. At least one character from each selected set is always included.
❌
Excluded Characters
Enter easily confused characters like 0 (zero), O (uppercase O), l (lowercase L), and 1 (one) to exclude them from generation.
🛡️
Crypto API Randomness
Uses your browser's built-in Crypto API to generate mathematically unpredictable, secure random numbers.

Basic Usage

1

Set the Length

Drag the slider to set your password length. We recommend 16+ characters for typical services and 24+ for important accounts.

2

Choose the Character Set

Choose which to include -- uppercase, lowercase, digits, symbols. The more you select, the stronger the password.

3

Choose a Count (Optional)

Choose 1, 5, or 10. Generate several at once and pick the one you like.

4

Generate and Copy

Click the 🔑 Generate Password button. Copy to your clipboard with the Copy button next to each password, or 📋 Copy All.

Why Use the Crypto API?

The ordinary Math.random() generates pseudo-random numbers. If the initial seed is predictable, the values it produces are too, which is a security weakness.

PasswordGen uses the browser's built-in crypto.getRandomValues(). This function generates mathematically unpredictable random numbers based on the operating system's hardware entropy sources (mouse movement, keyboard timing, and more), making it well suited for password generation.

🔒 PasswordGen processes everything entirely in your browser. The generated password is never sent to an external server, and its history disappears when you refresh the page. We recommend saving it to a password manager the moment you generate it.

Usage Tips

Generate Several and Pick the One You Like

Generate 10 at once and pick whichever is easiest to remember or type. Since the security strength is the same, feel free to choose based on convenience.

Use It with a Password Manager

Strong passwords are hard to remember. Generate one with PasswordGen and save it in a password manager like 1Password, Bitwarden, or KeePass. We recommend setting the password manager's own master key to a very strong password of 24+ characters.

Export Them All at Once with Copy All

Generate 10, then click 📋 Copy All to copy the whole list to your clipboard, one per line. Paste it into Notion or a text editor to organize.

Frequently Asked Questions

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Is what I enter sent to a server?

No. All processing happens entirely in your browser, and what you enter is never sent to or stored on an external server.

Q. Is the generated password stored anywhere?

No. The password is generated using your browser's secure random number generator and is never stored or sent anywhere.

Yes, it works the same way in a mobile browser without needing to install any app.
