Generate QR Code: The Complete Guide

June 19, 2026

Want to put a URL on a business card or poster as a QR code, but most sites make you install a paid app or sign up first? QRCode is a free online tool that instantly generates a QR code from a URL, text, or contact info. Make one right in your browser with no app to install, and download the generated QR code as a PNG right away. Whatever you enter never leaves your browser throughout the entire conversion into a QR image.

Key Features

🌐
URL QR Code
Generate a QR code from a website address. https:// is added automatically, so you can enter just the domain.
📝
Text QR Code
Generate a QR code from any free-form text -- a note, an announcement, a code, or anything else.
👤
Contact QR Code
Enter a name, phone number, email, organization, and website, and it's automatically converted into vCard format as a QR code.
🎨
Size and Color Settings
Freely set the size (128 / 256 / 512px) and foreground/background colors. PNG download is supported too.

Basic Usage

1

Choose a Tab

Choose the type of content to encode from the tabs at the top -- URL, Text, or Contact.

2

Enter Content

Enter content matching the tab you chose. A QR code is generated live in the preview on the right the instant you type.

3

Set Options (Optional)

Adjust the QR code size (128 / 256 / 512px) and foreground/background colors however you want.

4

Download the PNG

Click the ⬇ Download PNG button to save it as qrcode_result.png.

Input Guide by Tab

🌐 URL Tab

Enter a website address. If https:// is missing when the field loses focus, it's added automatically. For example, entering browserkit.online becomes https://browserkit.online.

📝 Text Tab

Enter whatever content you want, freely. How much data a QR code can hold depends on the length and complexity of the content. Longer text makes the QR pattern more complex and harder to scan, so we recommend keeping it short when possible.

👤 Contact Tab

Automatically converted into vCard format, so scanning it with a smartphone camera saves it directly to contacts.

Size and Color Settings

Choosing a Size

SizeUse
128pxSmall print, business cards, stickers
256px (default)General use, web posts, inserting into documents
512pxLarge posters, banners, high-resolution printing

Setting Colors

Freely set the foreground color (the QR code pattern) and background color. However, for reliable scanning, there needs to be enough brightness contrast between them.

⚠️ Warning: If the foreground and background colors are too similar, scanning may fail. A dark foreground plus a light background is recommended. The default -- black (#000000) plus white (#ffffff) -- scans most reliably.

Making a Wi-Fi QR Code

Choose the Text tab and enter the format below to create a QR code that automatically connects to Wi-Fi when scanned with a smartphone camera.

WIFI:T:WPA;S:my_network_name;P:my_password;;
FieldDescriptionExample
T:WPASecurity type (WPA for WPA/WPA2, nopass if none)T:WPA
S:nameWi-Fi network name (SSID)S:MyWifi
P:passwordWi-Fi passwordP:mypassword123
💡 QRCode processes everything entirely in your browser. Since the URL, text, or contact info you enter is never sent to an external server, you can safely turn personal information or internal URLs into QR codes too.

Frequently Asked Questions

Q. Is the Generate QR Code tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Is what I enter sent to a server?

No. All processing happens entirely in your browser, and what you enter is never sent to or stored on an external server.

Q. Does the generated QR code expire?

No. Since the information is encoded directly into the QR code image itself, it works indefinitely with no expiration.

Q. Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
