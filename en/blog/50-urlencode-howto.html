URL Encoder: The Complete Guide

July 9, 2026

Ever wondered what a string like "%EC%95%88%EB%85%95" in the address bar actually means? That's what happens when non-ASCII text ends up in a URL. URLEncode is a free online tool for encoding and decoding text as a URL, parsing a complex query string into a table, or assembling a query URL from key-value pairs. All processing happens entirely in your browser, so your text is never sent to an external server.

Key Features

🔐
URL Encode/Decode
Choose between encodeURIComponent and encodeURI to encode or decode text.
🔍
Query Parameter Parsing
Paste a full URL or query string, and each parameter is laid out in a key-value table.
🔧
Query Builder
Enter a base URL and key-value pairs, and get a finished URL with encoding handled automatically.
🔒
Fully Local Processing
All conversion runs inside your browser. Since your text is never sent to a server, you can safely use it with private data too.

Tab Layout

🔐 Encode/Decode
🔍 Query Parsing

The Encode/Decode tab converts a piece of text, the Query Parsing tab analyzes a finished URL, and the Query Builder tab assembles a new URL.

Using Encode/Decode

1

Choose an Encoding Method

Choose either encodeURIComponent or encodeURI. See the Comparing the Two Methods table below to pick the right one for your situation.

2

Enter Text

Type the text you want to encode, or the URL-encoded string you want to decode, into the input box on the left.

3

Check and Copy the Result

Copy it to your clipboard with the 📋 Copy Result button, or move the result back into the input with the ⇄ Swap Input/Output button to convert it the other way.

Comparing the Two Methods

MethodWhat It EncodesWhen to Use
encodeURIComponent Encodes everything, including URL delimiters like & = ? / : # ; , + When encoding a single piece of a URL, like a query parameter value or form data
encodeURI Preserves delimiters needed for URL structure, like : / ? # & = When encoding an entire URL (path + query) all at once

Encoding Example

Input
https://example.com/search?q=hello world
encodeURIComponent
https%3A%2F%2Fexample.com%2Fsearch%3Fq%3Dhello%20world
Input
https://example.com/search?q=hello world
encodeURI
https://example.com/search?q=hello%20world

encodeURI leaves URL structure characters like :, /, ?, and = untouched, and only encodes characters -- like spaces or non-ASCII text -- that can't appear as-is in a URL.

Using Query Parsing

1

Paste a URL or Query String

Paste a full URL (https://...?a=1&b=2) or just a query string (a=1&b=2). The domain and path before the ? are automatically excluded from parsing.

2

Check the Parameter Table

Each parameter appears in a key-value table. A + is automatically decoded as a space, and parameters with no value are shown as empty.

3

Copy a Value or Export as JSON

Copy an individual value with the Copy button on its row, or copy every parameter at once as a JSON object with the 📋 Copy as JSON button.

Using the Query Builder

1

Enter a Base URL (Optional)

Enter just the domain and path. If left blank, only the query string (?key=value&...) is assembled.

2

Enter Key-Value Pairs

Add rows with the + Add Parameter button and enter a key and value in each. Values are automatically URL-encoded when assembled.

3

Copy the URL

The assembled URL is shown live at the bottom. Use it right away with the 📋 Copy URL button.

⚠️ Note: The Query Builder uses URLSearchParams to encode values automatically. If you enter an already-encoded value, it may get double-encoded, so enter the original (decoded) value as-is.

Use Cases

🔗
Checking a Shared Link's Parameters

📡

🇰️

Encode a path or search term containing Korean, Japanese, or other non-Latin text so it can be safely placed in a URL.
🐛
Debugging a Broken URL
Decode a double-encoded or broken URL to trace back what the original value was.

Frequently Asked Questions

Q. Is the URL Encoder tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Is what I enter sent to a server?

No. All processing happens entirely in your browser, and what you enter is never sent to or stored on an external server.

Q. Does it handle URLs containing non-ASCII characters?

Yes, it converts non-ASCII characters into UTF-8-based percent-encoding and can restore them back.

Q. Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
