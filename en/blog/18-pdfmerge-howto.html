Merge PDF: The Complete Guide

June 16, 2026

When a scanned document is scattered across 3-4 separate files, attaching them one by one in the right order every time you submit them gets tedious. PDFMerge is a free online tool for combining multiple PDFs into one, or extracting just the pages you need. It works instantly with no install, and everything happens entirely in your browser, so your PDF files are never sent to an external server.

Key Features

📄
Multi-PDF Upload
Upload multiple PDF files at once. Both drag-and-drop and file selection are supported.
🖼️
Thumbnail Preview
Renders the first page of each file as a thumbnail so you can identify files visually.
↕️
Reorder by Dragging
Drag file cards to freely adjust the order they'll be merged in.
📑
Page Range Selection
Specify which pages to include per file (e.g., 1-3, 5). Leave it blank to include every page.
➕
Add / Remove Files
Add more files or remove individual ones even after uploading.
📥
Download the PDF
Instantly download the finished file as pdfmerge_result.pdf.

Basic Usage

1

Upload PDF Files

Drag PDF files onto the upload area, or click it to select files. You can select multiple files at once.

2

Check the File List

Uploaded files are shown as cards. Each card shows the filename, page count, file size, and a thumbnail of the first page. Use the + Add File button to add more.

3

Reorder Files and Enter Page Ranges

Drag a card to adjust the merge order. To include only specific pages, enter a range in the page range field (e.g., 1-3, 5 → includes only pages 1, 2, 3, and 5).

4

Merge and Download the PDF

Click the Merge & Download PDF button. Processing time varies with page count, and progress is shown with a progress bar. Once finished, pdfmerge_result.pdf downloads automatically.

5

Start Over

Use the Start Over button to reset and begin a new task.

How to Enter Page Ranges

Leave the page range field blank to include every page of that file. You can enter ranges in several ways, as shown below.

⚠️ Text is not selectable: PDFMerge works by re-rendering each page as an image before merging. As a result, the original PDF's text is converted into an image, not selectable, searchable, or copyable text. This may not suit documents that need to keep their text intact (searching contract text, materials you need to copy text from, etc.). It's best suited for merging scans or image-heavy PDFs.
💡 Very large PDFs or a large number of files can run into browser memory limits. We recommend 5 files or fewer and a total of 50 pages or fewer. Having many other tabs open during processing can slow things down.

Frequently Asked Questions

Q. Is the Merge PDF tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Are uploaded files sent to a server?

No. All processing happens entirely in your browser, and uploaded files are never sent to or stored on an external server.

Q. Is there a limit on how many PDFs I can merge?

There is no fixed limit. However, if files are very large or numerous, processing time may increase depending on your device's performance.

Q. Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
