Split PDF: The Complete Guide

July 9, 2026

You need to send just the signature page from a scanned contract PDF, but sending the whole file feels excessive. PDFSplit is a free online tool for splitting one PDF page by page, or extracting just the range you choose. When splitting into multiple individual files, you can download them all at once as a ZIP, and everything happens entirely in your browser, so your uploaded PDF is never sent to an external server.

Key Features

📄
Split by Page
Turns every page into its own PDF file, bundled into a single ZIP download. You can also select just the pages you want to split out.
✂️
Split by Range
Enter a range like "1-3, 5" and those pages alone are extracted into a single PDF.
🖼️
Page Preview
Once uploaded, every page shows as a thumbnail in a grid, so you can see and select pages by number visually.
🔒
Fully Local Processing
Everything from PDF rendering to splitting and zipping happens in your browser, so your file is never sent to a server.

How to Use It

1

Upload a PDF

Click the upload zone or drag a PDF file onto it. Only one file can be uploaded at a time. Once uploaded, a thumbnail is generated automatically for every page.

2

Choose a Split Mode

Pick the mode you want from the tabs at the top.

📄 Split by Page ✂️ Split by Range

Split by Page

3

Select Pages to Split

All pages are selected by default. Click a thumbnail to select or deselect it, or use the Select All / Deselect All buttons to adjust everything at once. Each selected page becomes its own PDF file.

Split by Range

3

Enter a Page Range

Enter the page range you want in the input field (e.g., 1-3, 5). Leave it blank to extract every page into a single PDF.

4

Split and Download

Click the ⬇ Split & Download button. In Split by Page mode, pdfsplit_pages.zip downloads; in Split by Range mode, pdfsplit_range.pdf downloads.

Split by Page vs. Split by Range -- When to Use Which?

ModeOutputBest For
Split by Page One PDF per selected page (bundled in a single ZIP) When you want each page as a fully independent file to share or store separately
Split by Range A single PDF containing just the pages you set When you want to excerpt just the part you need from a larger document into one file

Use Cases

📑
Separating Contract Clauses
Pull out just the pages containing a specific clause from a long contract and share them as a separate PDF.
📚
Splitting a Batch-Scanned Document
Split a PDF made from scanning several documents at once back into individual documents, page by page.
📊
Extracting a Report Summary
Extract just the summary and conclusion pages from a full report to share a shorter version.
📤
Getting Around Attachment Size Limits
When an attachment size limit is in your way, extract just the pages you need to shrink the file before sending.
🔒 PDFSplit processes everything entirely in your browser. Since uploaded PDFs are never sent to an external server, you can safely split sensitive documents like contracts and reports too.

Frequently Asked Questions

Q. Is the Split PDF tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Q. Are uploaded files sent to a server?

No. All processing happens entirely in your browser, and uploaded files are never sent to or stored on an external server.

Q. Can I extract just specific pages?

Yes, you can set a page range and save just the part you need as a separate PDF.

Q. Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
