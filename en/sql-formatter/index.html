Frequently asked questions

Is the SQL Formatter tool really free?

Yes, it is completely free to use with no sign-up or installation required. There is no usage limit either.

Is what I enter sent to a server?

No. All processing happens entirely in your browser, and your input is never sent to or stored on an external server.

Which SQL syntax does it support?

It cleans up indentation and line breaks based on common standard SQL syntax to make queries easier to read.

Can I use this on mobile?

Yes, it works the same way in a mobile browser without needing to install any app.
