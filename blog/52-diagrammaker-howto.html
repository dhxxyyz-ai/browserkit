다이어그램 생성기 사용법 완전 가이드

2026년 7월 9일

DiagramMaker는 Mermaid 문법을 입력하면 플로우차트, 시퀀스, ER, 간트, 파이 다이어그램을 즉시 그려주는 무료 온라인 다이어그램 생성기입니다. 5가지 프리셋을 제공해 문법을 몰라도 바로 시작할 수 있고, 완성된 다이어그램을 SVG나 PNG로 저장할 수 있습니다. 모든 렌더링이 브라우저 내에서만 이루어지므로 입력한 다이어그램 내용이 외부 서버로 전송되지 않습니다.

주요 기능

🎨
5가지 프리셋
플로우차트, 시퀀스, ER, 간트, 파이 다이어그램의 완성된 예시 코드를 원클릭으로 불러옵니다.
👁️
실시간 미리보기
Mermaid 문법을 입력하면 0.4초 뒤 자동으로 다이어그램이 다시 렌더링됩니다.
⚠️
문법 오류 안내
문법이 틀리면 다이어그램 대신 오류 메시지를 표시해 어디가 잘못됐는지 바로 알 수 있습니다.
⬇
SVG/PNG 다운로드
완성한 다이어그램을 벡터(SVG) 또는 이미지(PNG, 2배 해상도) 파일로 저장합니다.

사용법

1

프리셋 선택

상단 5개 프리셋 버튼 중 원하는 다이어그램 종류를 선택합니다. 클릭하면 해당 종류의 완성된 예시 코드가 입력창에 자동으로 채워집니다.

🔀 플로우차트 🔁 시퀀스 🗃️ ER 다이어그램 📅 간트차트 🥧 파이차트
2

코드 수정

왼쪽 입력창의 Mermaid 문법을 직접 수정합니다. 노드 이름, 화살표 방향, 라벨 등을 원하는 내용으로 바꾸면 오른쪽 미리보기가 자동으로 갱신됩니다.

3

다른 프리셋 확인

시퀀스, ER, 간트, 파이 다이어그램도 같은 방식으로 프리셋을 불러와 문법 구조를 확인하고 응용할 수 있습니다.

4

다운로드 또는 코드 복사

⬇ SVG 다운로드로 벡터 파일을, ⬇ PNG 다운로드로 이미지 파일을 저장합니다. 📋 코드 복사 버튼으로 Mermaid 코드 자체를 복사해 노션, GitHub 등 Mermaid를 지원하는 곳에 붙여넣을 수도 있습니다.

Mermaid 문법 기본 예시

플로우차트는 flowchart 키워드와 방향(TD=위→아래, LR=왼쪽→오른쪽)으로 시작하고, 화살표로 노드를 연결합니다.

flowchart TD A[시작] --> B{조건} B -- 예 --> C[결과 A] B -- 아니오 --> D[결과 B]
⚠️ 참고: DiagramMaker는 오픈소스 라이브러리 Mermaid.js를 그대로 사용합니다. 더 다양한 다이어그램 문법과 옵션은 Mermaid 공식 문서에서 확인할 수 있습니다.

다이어그램 종류별 용도

종류키워드주요 용도
플로우차트flowchart업무 흐름, 의사결정 분기, 알고리즘 로직 표현
시퀀스 다이어그램sequenceDiagram시스템 간 메시지 교환, API 호출 순서 표현
ER 다이어그램erDiagram데이터베이스 테이블 구조와 관계 표현
간트차트gantt프로젝트 일정, 작업 기간과 순서 표현
파이차트pie비율, 점유율 데이터 시각화

활용 예시

📝
기획 문서용 다이어그램
서비스 기획서나 회의 자료에 넣을 업무 흐름도를 빠르게 그려 이미지로 첨부합니다.
🗄️
DB 설계 검토
ER 다이어그램으로 테이블 관계를 시각화해 팀원과 데이터베이스 설계를 검토합니다.
📅
프로젝트 일정 공유
간트차트로 개발 단계별 일정을 정리해 팀에 공유하거나 발표 자료에 삽입합니다.
📖
문서용 코드 재사용
완성한 Mermaid 코드를 복사해 노션, GitHub README 등 Mermaid를 지원하는 문서에 그대로 붙여넣습니다.
🔒 DiagramMaker는 모든 렌더링이 내 PC 브라우저에서만 실행됩니다. 입력한 다이어그램 내용이 외부 서버로 전송되지 않아 비공개 프로젝트의 구조도도 안심하고 그릴 수 있습니다.

Mermaid 문법으로 플로우차트, 시퀀스, ER, 간트, 파이 다이어그램을 그려보세요.
SVG 또는 PNG로 바로 저장할 수 있습니다.
