색상 대비 검사기 사용법 완전 가이드

2026년 7월 24일

버튼 글자색이 예뻐 보여서 골랐는데, 막상 밝은 화면에서 보면 배경과 거의 구분이 안 되는 경험 있으신가요? 디자인 시안에서는 괜찮아 보여도 실제로는 저시력자나 야외에서 화면을 보는 사용자에게 전혀 읽히지 않는 색 조합일 수 있습니다. ColorContrastChecker는 텍스트 색상과 배경 색상만 입력하면 WCAG 2.1 기준 명도 대비를 계산해 AA·AAA 등급을 통과하는지 즉시 알려주는 무료 온라인 도구입니다. 모든 계산은 브라우저에서만 이루어집니다.

주요 기능

⚖️
WCAG 명도 대비 계산
두 색상의 상대 휘도를 계산해 1:1~21:1 사이의 정확한 대비 비율을 알려줍니다.
✅
AA·AAA 등급 자동 판정
일반 텍스트·큰 텍스트 기준 4가지 WCAG 등급의 통과 여부를 한눈에 보여줍니다.
👁️
실시간 미리보기
입력한 색상 조합으로 실제 텍스트가 어떻게 보이는지 큰 글씨·본문 글씨로 바로 확인합니다.
🔒
완전 로컬 처리
입력한 색상이 브라우저 안에서만 계산되고 서버로 전송되지 않습니다.

사용법

1

텍스트·배경 색상 입력

HEX 코드를 직접 입력하거나 색상 선택기로 텍스트 색상과 배경 색상을 고릅니다.

2

명도 대비와 미리보기 자동 확인

입력하는 즉시 대비 비율이 계산되고, 실제 색상 조합으로 큰 텍스트·일반 텍스트 미리보기가 표시됩니다.

3

AA·AAA 등급 통과 여부 확인

일반 텍스트·큰 텍스트 기준 4가지 등급의 통과·미달 여부가 표로 정리되어 나타납니다.

⚠️ 참고: WCAG는 "큰 텍스트"를 18pt(24px) 이상이거나 14pt(약 19px) 이상이면서 굵게 표시된 텍스트로 정의합니다. 그 외에는 모두 "일반 텍스트" 기준이 적용됩니다.

WCAG 2.1 명도 대비 계산 방식

등급최소 대비
AA · 일반 텍스트4.5 : 1 이상
AAA · 일반 텍스트7 : 1 이상
AA · 큰 텍스트3 : 1 이상
AAA · 큰 텍스트4.5 : 1 이상
💡 실제 계산 예시: 흰 배경(#FFFFFF)에 회색 텍스트 #767676을 올리면 → 명도 대비는 약 4.54:1로 AA 일반 텍스트 기준(4.5:1)은 간신히 통과하지만 AAA 기준(7:1)은 통과하지 못합니다. 반면 완전한 검정(#000000)과 흰색(#FFFFFF)의 대비는 21:1로 모든 등급을 통과하는 최댓값입니다. 색을 살짝만 흐리게 해도 접근성 기준을 못 맞출 수 있다는 걸 보여주는 예시입니다.

활용 예시

🎨
디자인 시안 검증
시안에서 정한 텍스트·배경 색상 조합이 접근성 기준을 통과하는지 미리 확인합니다.
💻
프론트엔드 개발
CSS에 색상 값을 적용하기 전에 HEX 코드만으로 빠르게 대비를 검사합니다.
🏢
공공·기업 웹사이트 점검
접근성 지침 준수가 요구되는 사이트의 색상 조합을 점검합니다.
📱
앱 UI 색상 검토
버튼·배지 등 UI 요소의 텍스트 가독성을 색상 확정 전에 확인합니다.
🔒 ColorContrastChecker는 모든 계산이 내 PC 브라우저에서만 실행됩니다. 입력한 색상 정보가 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. WCAG AA·AAA는 무엇을 기준으로 하나요?

WCAG 2.1 기준으로 일반 텍스트는 AA 4.5:1 이상, AAA 7:1 이상, 큰 텍스트(18pt 이상 또는 14pt 굵게)는 AA 3:1 이상, AAA 4.5:1 이상을 통과 기준으로 봅니다.

Q. 색상 대비 검사기는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 검사 횟수 제한도 없습니다.

Q. 입력한 색상 정보가 서버로 전송되나요?

아니요. 모든 계산은 브라우저 안에서만 이루어지며 입력한 색상이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 왜 접근성 기준을 지켜야 하나요?

대비가 낮은 텍스트는 저시력자·색약자뿐 아니라 야외에서 화면을 보는 일반 사용자에게도 읽기 어렵습니다. 공공기관·기업 웹사이트는 접근성 지침 준수가 요구되는 경우가 많습니다.

지금 바로 색상 대비를 검사해보세요.
설치도 회원가입도 필요 없습니다.
