단위 변환기 사용법 완전 가이드

2026년 6월 20일

해외 직구 사이트에서 "5 lbs"라고 적힌 무게가 몇 kg인지, 원단 폭이 "60 inch"면 몇 cm인지 매번 검색창에 물어보고 계신가요? UnitConvert는 길이·무게·온도·넓이·속도를 실시간으로 변환하는 무료 온라인 단위 변환기입니다. 값을 입력하면 지원하는 모든 단위의 변환 결과가 한 번에 표시되고, 각 결과를 클릭 한 번으로 복사할 수 있습니다. 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

주요 기능

⚡
실시간 변환
값을 입력하는 즉시 지원하는 모든 단위의 결과가 표에 표시됩니다. 별도의 변환 버튼이 필요 없습니다.
📊
전체 단위 표
선택한 카테고리의 모든 단위를 한 화면에서 확인할 수 있습니다. 현재 선택 단위는 보라색으로 하이라이트됩니다.
📋
결과 복사
각 단위 결과 옆의 복사 버튼으로 값과 단위 기호를 클립보드에 바로 복사합니다.
🗂️
5가지 카테고리
길이, 무게, 온도, 넓이, 속도 탭을 선택해 카테고리별로 변환합니다. 총 32개 단위를 지원합니다.

기본 사용법

1

카테고리 탭 선택

상단 탭에서 변환할 카테고리를 선택합니다. 길이 / 무게 / 온도 / 넓이 / 속도 중 하나를 선택하세요.

2

기준 단위 선택

드롭다운에서 입력값의 단위를 선택합니다. 예를 들어 100km를 다른 단위로 변환하려면 드롭다운에서 '킬로미터(km)'를 선택합니다.

3

값 입력

입력창에 변환할 숫자를 입력합니다. 입력하는 즉시 아래 표에 모든 단위의 변환 결과가 표시됩니다.

4

결과 복사 (선택)

원하는 단위 행의 복사 버튼을 클릭하면 값과 단위 기호가 함께 클립보드에 복사됩니다.

온도는 단순 비율 변환이 아닌 공식을 사용해 정확하게 변환합니다.

단위명기호변환 공식 (섭씨 기준)
섭씨°C기준 단위
화씨°F°F = °C × 9/5 + 32
켈빈KK = °C + 273.15
🌡️ 온도 변환 예시: 100°C = 212°F = 373.15K. 섭씨 0°C는 화씨 32°F, 켈빈 273.15K입니다. 절대영도는 -273.15°C = 0K입니다.

활용 예시

✍️
해외 레시피 단위 변환
미국 레시피의 oz(온스), lb(파운드)를 g(그램)으로 변환해 계량합니다.
🏠
부동산 평수 계산
아파트 전용면적(m²)을 평으로 변환하거나, 평을 m²로 환산합니다.
✈️
여행 단위 변환
미국·영국 여행 시 마일 → km, 화씨 → 섭씨, 파운드 → kg을 빠르게 변환합니다.
💻
개발·설계 작업
인치·픽셀·cm 등 디자인/제조 작업에서 필요한 단위를 즉시 변환합니다.
⛵
항법·운항
선박·항공기 속도를 노트, km/h, mph, m/s 등으로 빠르게 변환합니다.
📚
학습·과학 계산
물리·화학 수업에서 SI 단위와 관습 단위 사이를 빠르게 변환합니다.
📐 UnitConvert는 모든 처리가 브라우저 내에서만 이루어집니다. 입력한 값이 외부 서버로 전송되지 않으며, 인터넷 연결 없이도 사용할 수 있습니다.

자주 묻는 질문

Q. 단위 변환기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 어떤 단위들을 변환할 수 있나요?

길이, 무게, 온도, 넓이, 속도 등 일상과 업무에서 자주 쓰는 단위들을 상호 변환할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

길이·무게·온도·속도 단위를 입력하면 모든 단위로 동시에 변환됩니다.
단위 표를 통째로 확인하므로 따로 다시 검색할 필요가 없습니다.
