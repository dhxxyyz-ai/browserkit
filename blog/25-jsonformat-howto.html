JSON 포맷터 사용법 완전 가이드

2026년 6월 19일

API 응답으로 받은 JSON이 줄바꿈 하나 없이 한 줄로 뭉쳐 있으면 어디서부터 봐야 할지 막막합니다. JSONFormat은 그런 JSON을 보기 좋게 정렬하고, 압축하고, 유효성까지 검사해주는 무료 온라인 도구입니다. 설치나 회원가입 없이 브라우저에서 바로 쓸 수 있고, 입력한 JSON은 브라우저 안에서만 처리되어 외부 서버로 전송되지 않습니다. API 응답을 디버깅하거나 설정 파일을 검토할 때 특히 유용합니다.

주요 기능

✨
JSON 정렬 (Pretty Print)
압축된 JSON을 들여쓰기 2칸 또는 4칸으로 보기 좋게 펼쳐줍니다. 구문 강조 색상으로 키, 값, 타입을 구분해 읽기 쉽습니다.
🗜️
JSON 압축 (Minify)
불필요한 공백과 줄바꿈을 모두 제거해 JSON을 한 줄로 압축합니다. API 요청 본문 작성이나 용량 최소화에 활용하세요.
✅
실시간 유효성 검사
입력하는 즉시 JSON 문법 오류를 감지합니다. 오류가 있으면 행과 열 위치를 표시해 빠르게 수정할 수 있습니다.
🎨
구문 강조
키(보라색), 문자열(초록), 숫자(파랑), boolean(주황), null(빨강)으로 타입별 색상을 구분해 JSON 구조를 직관적으로 파악할 수 있습니다.

기본 사용법

1

JSON 입력

왼쪽 입력창에 JSON을 붙여넣습니다. 입력하는 즉시 유효성 검사가 실행되어 상단에 ✅ 유효 또는 ❌ 오류 상태가 표시됩니다.

2

정렬 또는 압축

✨ 정렬 (2칸) 또는 ✨ 정렬 (4칸) 버튼으로 들여쓰기를 적용하거나, 🗜️ 압축 버튼으로 공백을 제거합니다.

3

결과 복사

오른쪽 결과창 상단의 복사 버튼을 클릭하면 결과 JSON이 클립보드에 복사됩니다.

유효성 검사 상태 표시

입력창에 JSON을 입력하면 300ms 후 자동으로 유효성 검사가 실행됩니다.

✅ 유효한 JSON ❌ JSON 오류

오류가 감지되면 입력창 테두리가 빨간색으로 변하고, 오류 위치(행·열)와 오류 메시지가 표시됩니다. 이 정보를 참고해 JSON을 수정하면 됩니다.

정렬 vs 압축 비교

정렬 전 (압축된 상태)

{"name":"BrowserKit","tools":["JSONFormat","QRCode"],"free":true}

정렬 후 (들여쓰기 2칸)

{ "name": "BrowserKit", "tools": [ "JSONFormat", "QRCode" ], "free": true }

구문 강조 색상 가이드

타입색상예시
키 (Key)보라색"name", "version"
문자열 (String)초록색"BrowserKit", "https://..."
숫자 (Number)파란색42, 3.14, -1
불리언 (Boolean)주황색true, false
null빨간색null
괄호 (Bracket)흰색{, }, [, ]

들여쓰기 2칸 vs 4칸

옵션권장 상황
2칸 들여쓰기JavaScript, Node.js, 웹 개발 표준. 화면 공간을 효율적으로 사용
4칸 들여쓰기Python, Java 등 4칸을 표준으로 사용하는 환경. 가독성이 더 높음

자주 발생하는 JSON 오류

오류 유형잘못된 예올바른 예
작은따옴표 사용{'key': 'value'}{"key": "value"}
마지막 쉼표 (Trailing comma){"a": 1, "b": 2,}{"a": 1, "b": 2}
따옴표 없는 키{key: "value"}{"key": "value"}
주석 포함{"a": 1 // 주석}{"a": 1}
undefined 값{"a": undefined}{"a": null}

활용 예시

API 응답 분석

REST API나 GraphQL 응답을 개발자 도구에서 복사한 뒤 JSONFormat에 붙여넣고 정렬하면 중첩된 데이터 구조를 한눈에 파악할 수 있습니다.

설정 파일 검증

package.json, tsconfig.json, appsettings.json 등 JSON 형식의 설정 파일을 붙여넣어 문법 오류를 빠르게 찾을 수 있습니다. 특히 직접 편집 후 오류가 발생했을 때 유용합니다.

API 요청 본문 최소화

테스트용으로 정렬된 JSON을 작성한 뒤 압축 버튼으로 한 줄로 만들어 curl 명령어나 Postman에 바로 붙여넣을 수 있습니다.

샘플 JSON으로 빠른 테스트

📋 샘플 불러오기 버튼을 클릭하면 BrowserKit 서비스 데이터 형태의 샘플 JSON이 자동으로 로드됩니다. 도구의 동작 방식을 빠르게 확인할 수 있습니다.

💡 JSONFormat은 모든 처리가 브라우저 내에서만 이루어집니다. 입력한 JSON이 외부 서버로 전송되지 않으므로, API 키가 포함된 응답이나 내부 시스템 설정 파일도 안전하게 분석할 수 있습니다.

자주 묻는 질문

Q. JSON 포맷터 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 잘못된 JSON도 확인할 수 있나요?

네, 유효성 검사 기능이 문법 오류를 찾아 알려주므로 어디가 잘못됐는지 빠르게 확인할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
