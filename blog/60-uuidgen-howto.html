UUID 생성기 사용법 완전 가이드

2026년 7월 10일

UUIDGen은 개발할 때 자주 필요한 UUID(범용 고유 식별자)를 브라우저에서 즉시 생성하는 무료 온라인 도구입니다. 버튼 하나로 UUID 1개를 바로 만들 수 있고, 필요하면 한 번에 최대 1000개까지 대량 생성할 수 있습니다. 대문자, 하이픈 제거, 중괄호 감싸기 등 형식도 자유롭게 조합할 수 있어 다양한 개발 환경에 바로 붙여넣을 수 있습니다.

주요 기능

🎲
즉시 UUID 1개 생성
페이지를 열면 바로 UUID 하나가 표시되고, 새로고침 버튼으로 언제든 새로 생성합니다.
📦
최대 1000개 대량 생성
개수를 지정하면 원하는 만큼 UUID를 한 번에 생성해 목록으로 받습니다.
🔠
형식 옵션
대문자, 하이픈(-) 제거, 중괄호 {} 감싸기를 자유롭게 조합해 원하는 형식으로 만듭니다.
🔒
완전 로컬 처리
crypto.randomUUID()로 브라우저 안에서만 생성됩니다. 서버로 전송되지 않습니다.

사용법

1

UUID 1개만 필요할 때

페이지 상단에 UUID 하나가 자동으로 표시됩니다. ↺ 버튼으로 새로 생성하거나, 📋 버튼으로 바로 복사할 수 있습니다.

2

여러 개가 필요할 때 — 대량 생성 옵션 설정

생성 개수에 원하는 수(최대 1000)를 입력하고, 필요하면 대문자, 하이픈(-) 제거, 중괄호 {} 감싸기 옵션을 체크합니다.

3

생성하기 → 복사 또는 다운로드

🎲 생성하기 버튼을 누르면 결과 목록이 텍스트 영역에 표시됩니다. 📋 전체 복사로 클립보드에 담거나, ⬇ TXT 다운로드로 파일로 저장할 수 있습니다.

⚠️ 참고: UUIDGen이 생성하는 UUID는 모두 버전 4(v4, 무작위 기반)입니다. 특정 시점 순서를 보장하는 버전 1(타임스탬프 기반)이나 정렬 친화적인 ULID가 필요한 경우에는 적합하지 않을 수 있습니다. 대부분의 DB 기본키, 세션 ID, 더미 데이터 용도에는 v4로 충분합니다.

형식 옵션 예시

옵션결과 예시
기본값1c770af9-925d-4232-8cab-b6ffea98a212
대문자1C770AF9-925D-4232-8CAB-B6FFEA98A212
하이픈 제거1c770af9925d42328cabb6ffea98a212
중괄호 감싸기{1c770af9-925d-4232-8cab-b6ffea98a212}

활용 예시

🗄️
DB 기본키(Primary Key)
자동 증가 정수 대신 UUID를 기본키로 사용하는 테이블 설계에 활용합니다.
🧪
테스트·더미 데이터
테스트 픽스처나 목업 데이터에 필요한 고유 ID를 대량으로 빠르게 준비합니다.
🔑
세션·토큰 ID
임시 세션 식별자나 요청 추적 ID로 사용할 고유값을 즉시 만듭니다.
📁
파일·리소스 이름
업로드 파일명 충돌을 피하기 위한 고유 식별자로 활용합니다.
🔒 UUIDGen은 브라우저의 crypto.randomUUID()로 모든 UUID를 로컬에서 생성합니다. 서버로 전송되지 않습니다.

UUID(v4)를 즉시 생성하고 필요한 만큼 대량으로 만들어보세요.
형식 옵션과 TXT 다운로드까지 한 번에 처리할 수 있습니다.
