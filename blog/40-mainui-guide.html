BrowserKit 홈 화면 사용법 — 바탕화면처럼 쓰는 도구 모음

2026년 7월 4일

BrowserKit 홈 화면은 옛날 PC 바탕화면처럼 꾸며져 있습니다. 도구가 25개가 넘다 보니 긴 목록으로 나열하는 대신, 폴더와 아이콘으로 정리했어요. 처음 방문하면 낯설 수 있지만, 실제 컴퓨터 바탕화면을 쓰듯 클릭하면 그대로 동작합니다. 이 글에서 홈 화면 구석구석을 안내해 드릴게요.

①도구상자카테고리별 도구 아이콘 모음 — 클릭하면 소개 창이 열립니다

④작업 표시줄열려 있는 창 목록 표시와 전환
⑤검색도구 이름으로 바로 찾기

기본 사용법

1

도구상자에서 도구 열기

화면 왼쪽의 도구상자에는 개인정보, 이미지 편집, 문서·텍스트 등 카테고리별로 도구 아이콘이 정리되어 있습니다. 아이콘을 클릭하면 도구 소개 창이 열리고, 도구 열기 → 버튼을 누르면 해당 도구 페이지로 이동합니다.

2

검색으로 바로 찾기

원하는 도구 이름을 알고 있다면 검색이 가장 빠릅니다. 검색창에 도구 이름(한글 이름도 가능)을 입력하면 드롭다운에 후보가 나타나고, 클릭하면 소개 창이 바로 열립니다.

3

창 옮기기, 닫기, 전환하기

열린 창은 실제 컴퓨터처럼 조작합니다. 제목 표시줄을 드래그하면 창이 이동하고, 오른쪽 위 ✕ 버튼으로 닫습니다. 창을 여러 개 열었다면 아래 작업 표시줄에서 클릭해 전환할 수 있습니다.

4

시작 메뉴와 바탕화면 아이콘

왼쪽 아래 시작 버튼을 누르면 도구·블로그·정보 폴더로 이동하는 메뉴가 열립니다. 화면 오른쪽의 바탕화면 아이콘(내 컴퓨터, 블로그, 정보 등)을 더블 클릭하듯 눌러도 같은 폴더가 열립니다. 블로그 폴더에서는 글 목록이 파일처럼 표시되고, 클릭하면 미리보기 창을 거쳐 글 전체를 읽을 수 있습니다.

숨은 재미 요소

홈 화면에는 실용성과 별개로 소소한 재미 요소들이 숨어 있습니다. 휴지통을 열면 "휴지통이 비어 있어요"라는 안내가 나오고, 내 컴퓨터를 열면 전체 폴더 구조를 탐색할 수 있습니다. 화면 색감이 마음에 안 든다면 테마를 바꿔 벽지와 창 색상을 통째로 바꿀 수도 있어요. 기능에 영향은 없으니 부담 없이 눌러보세요.

모바일에서는 화면이 다릅니다

스마트폰처럼 화면이 좁은 기기(768px 이하)에서 접속하면 바탕화면 대신 모바일 전용 홈이 표시됩니다. 상단에 고정된 로고 아래로 카테고리별 도구 아이콘이 격자로 정렬되고, 아이콘을 누르면 소개 창 없이 도구 페이지로 바로 이동합니다. 화면은 달라도 제공되는 도구는 동일합니다.

💡 어느 화면에서든 각 도구 페이지 상단의 "사용법 가이드 보기" 링크를 누르면 해당 도구의 완전 가이드 글로 이동합니다. 도구 사용법이 궁금할 때 활용하세요.

자주 묻는 질문

Q. 메인 화면에서 원하는 도구를 어떻게 찾나요?

바탕화면의 폴더를 열어 카테고리별로 찾거나, 하단 작업표시줄의 검색창에 도구 이름을 입력하면 바로 찾을 수 있습니다.

Q. 모바일에서도 같은 화면을 쓰나요?

모바일에서는 화면 크기에 맞춘 전용 화면이 자동으로 열립니다. 제공되는 도구는 동일합니다.

Q. 도구 창을 여러 개 동시에 열 수 있나요?

네, 데스크톱 메타포 UI라 여러 창을 동시에 열고 이동하며 사용할 수 있습니다.
