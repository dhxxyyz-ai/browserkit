표 변환기 사용법 완전 가이드

2026년 7월 13일

MarkdownTableConvert는 마크다운 표, CSV, HTML 표 세 가지 형식을 서로 자유롭게 변환해주는 무료 온라인 도구입니다. 입력 형식과 출력 형식을 각각 선택하기만 하면 여섯 가지 조합 어떤 방향으로든 즉시 변환되며, 변환 결과는 표로 미리볼 수 있습니다. README 작성, 스프레드시트 데이터를 문서에 옮기기, 웹페이지 표 추출 등에 유용하며 모든 처리는 브라우저에서만 이루어집니다.

주요 기능

🔄
3형식 상호 변환
마크다운·CSV·HTML 중 어떤 형식에서 어떤 형식으로든 변환할 수 있습니다.
📁
파일 업로드 지원
.md, .csv, .html 파일을 드래그하면 확장자에 맞춰 입력 형식이 자동 선택됩니다.
📊
표 미리보기
변환된 데이터를 실제 표 형태로 미리 확인할 수 있습니다.
🔒
완전 로컬 처리
표 데이터가 브라우저 안에서만 변환되고 서버로 전송되지 않습니다.

사용법

1

입력·출력 형식 선택

상단에서 입력 형식과 출력 형식을 각각 마크다운·CSV·HTML 중에서 선택합니다. 예를 들어 마크다운 표를 CSV로 바꾸려면 입력을 마크다운, 출력을 CSV로 선택하세요.

2

표 데이터 입력

왼쪽 입력창에 표 데이터를 붙여넣거나, 📁 파일 업로드 영역에 .md·.csv·.html 파일을 드래그해 올립니다. 파일을 올리면 확장자에 맞는 입력 형식이 자동으로 선택됩니다.

3

변환 및 결과 확인

🔄 변환하기 버튼을 누르면 오른쪽에 변환된 결과가 표시되고, 아래 표 미리보기에서 실제 표 모양을 바로 확인할 수 있습니다. 📋 결과 복사 또는 ⬇ 파일 다운로드로 바로 활용하세요.

⚠️ 참고: 첫 행을 항상 헤더로 인식하는 간단한 자체 파서를 사용합니다. 마크다운 표에서 셀 안에 파이프(|) 문자가 필요하면 \|로 이스케이프해주세요. 매우 복잡하거나 표준을 벗어난 표는 결과가 다를 수 있으니 변환 후 표 미리보기로 꼭 확인하세요.

지원 형식 정리

형식설명
마크다운| 헤더 | 형식의 GitHub 스타일 마크다운 표 — README, 위키 문서에 주로 사용
CSV쉼표로 구분된 값 — 엑셀, 구글 시트에서 바로 붙여넣기 가능
HTML<table> 태그 기반 표 — 웹페이지에 바로 삽입 가능

활용 예시

📝
README 표 작성
스프레드시트 데이터를 마크다운 표로 변환해 README.md에 붙여넣습니다.
📄
엑셀 데이터를 문서로
CSV로 내보낸 엑셀 데이터를 마크다운이나 HTML 표로 바로 변환합니다.
🌐
웹페이지 표 추출
HTML 표 소스를 CSV로 변환해 스프레드시트에서 다시 활용합니다.
💻
블로그·문서 표 삽입
마크다운 표를 HTML로 변환해 정적 사이트나 CMS에 바로 붙여넣습니다.
🔒 MarkdownTableConvert는 모든 변환이 내 PC 브라우저에서만 실행됩니다. 업로드한 표 데이터가 외부 서버로 전송되지 않습니다.

지금 바로 표를 원하는 형식으로 변환해보세요.
설치도 회원가입도 필요 없습니다.
