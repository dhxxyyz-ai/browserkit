즐겨찾기 아이콘 생성기 사용법 완전 가이드

2026년 7월 10일

FaviconGen은 이미지 1장을 업로드하면 웹사이트에 필요한 다양한 크기의 파비콘 세트와 favicon.ico 파일을 즉시 생성하는 무료 온라인 도구입니다. 16px부터 512px까지 6가지 크기를 한 번에 만들고, 바로 붙여넣을 수 있는 HTML 코드까지 함께 제공합니다. 모든 처리가 브라우저 내에서만 이루어지므로 업로드한 이미지가 외부 서버로 전송되지 않습니다.

주요 기능

🖼️
6종 크기 세트 생성
16, 32, 48, 180(Apple), 192, 512px 크기의 PNG를 한 번에 생성합니다.
📁
favicon.ico 생성
16/32/48px을 하나로 묶은 멀티 해상도 favicon.ico 파일을 직접 만듭니다.
📋
HTML 코드 자동 생성
<link> 태그 코드를 바로 복사해 <head>에 붙여넣을 수 있습니다.
🔒
완전 로컬 처리
모든 이미지 처리가 브라우저 안에서 실행됩니다. 업로드한 이미지가 서버로 전송되지 않습니다.

사용법

1

이미지 업로드

업로드 존을 클릭하거나 로고·아이콘 이미지를 드래그해 올립니다. 정사각형이 아닌 이미지는 가운데를 기준으로 자동으로 정사각형으로 잘립니다.

2

크기별 미리보기 확인

16×16부터 512×512까지 각 크기의 파비콘 카드에서 실제 크기로 어떻게 보이는지 확인합니다. 작은 크기(16, 32px)에서 로고가 뭉개지지 않는지 미리 점검할 수 있습니다.

3

HTML 코드 복사

📋 HTML 코드 복사 버튼으로 <link rel="icon"> 태그 5줄을 클립보드에 복사해 웹사이트 <head>에 붙여넣습니다.

4

ZIP 다운로드

⬇ 전체 ZIP 다운로드 버튼으로 6개 PNG 파일, favicon.ico, HTML 스니펫을 압축 파일 하나로 받습니다. 개별 크기만 필요하다면 각 카드의 ⬇ PNG 다운로드 버튼을 사용합니다.

⚠️ 참고: 생성된 favicon.ico는 PNG 이미지를 그대로 담는 최신 방식(Windows Vista 이후 표준)으로 만들어집니다. 아주 오래된 프로그램(Windows XP 시절 소프트웨어 등)과의 호환성이 필요하다면 별도의 BMP 기반 ICO 변환 도구를 사용해야 할 수 있습니다. 대부분의 최신 브라우저와 운영체제에서는 문제없이 작동합니다.

생성되는 파일 목록

파일명크기용도
favicon-16.png16×16브라우저 탭 아이콘(고밀도 디스플레이 제외)
favicon-32.png32×32브라우저 탭 아이콘(표준)
favicon-48.png48×48Windows 작업표시줄, 즐겨찾기
apple-touch-icon.png180×180iOS 홈 화면 추가 아이콘
favicon-192.png192×192안드로이드 홈 화면, PWA 아이콘
favicon-512.png512×512PWA 스플래시 화면, 고해상도 용도
favicon.ico16/32/48 통합레거시 브라우저 호환용 멀티 해상도 아이콘

활용 예시

🌐
개인 웹사이트/블로그
로고 이미지 하나로 사이트에 필요한 모든 파비콘 크기를 한 번에 준비합니다.
📱
PWA 아이콘 준비
192px, 512px 아이콘을 생성해 PWA manifest.json에 바로 등록합니다.
🎨
사이드 프로젝트 빠른 세팅
프로토타입이나 사이드 프로젝트에 어울리는 파비콘을 몇 초 만에 준비합니다.
👁️
작은 크기 미리보기
로고가 16px처럼 작은 크기에서도 알아볼 수 있는지 미리 확인합니다.
🔒 FaviconGen은 모든 이미지 처리가 내 PC 브라우저에서만 실행됩니다. 업로드한 이미지가 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. 즐겨찾기 아이콘 생성기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 어떤 크기의 파비콘이 만들어지나요?

16px, 32px 등 웹사이트에서 필요한 표준 크기의 파비콘을 한 번에 생성합니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
