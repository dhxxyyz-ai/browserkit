색상 팔레트 생성기 사용법 완전 가이드

2026년 7월 10일

메인 컬러 하나는 정했는데, 그 색과 어울리는 나머지 색상들을 고르려면 색채 이론을 알아야 할 것 같아 막막합니다. PaletteGen은 색상 1개만 입력하면 보색·유사색·삼각 배색·분할 보색·단색조 5가지 색상 조화 팔레트를 자동으로 생성하는 무료 온라인 도구입니다. 각 색상을 HEX·RGB·HSL로 바로 복사할 수 있고, 완성한 팔레트를 CSS 변수로 한 번에 내보낼 수도 있습니다. 모든 계산이 브라우저 안에서만 이루어지므로 입력한 색상이 외부 서버로 전송되지 않습니다.

주요 기능

🎨
5가지 색상 조화
보색, 유사색, 삼각 배색, 분할 보색, 단색조 중 원하는 조화 방식을 선택합니다.
🔢
HEX/RGB/HSL 동시 표시
각 색상 카드에서 세 가지 표기법을 모두 확인하고 개별적으로 클립보드에 복사할 수 있습니다.
📤
CSS 변수 내보내기
생성된 팔레트를 :root { --color-primary: ... } 형태의 CSS 변수 코드로 즉시 복사합니다.
🔒
완전 로컬 처리
모든 색상 계산이 브라우저 안에서 실행됩니다. 입력한 색상이 서버로 전송되지 않습니다.

사용법

1

기준 색상 입력

색상 선택기를 클릭하거나 HEX 입력창에 직접 코드를 입력합니다 (예: #7B6CFF). 3자리 축약형(#F0A)도 인식합니다.

2

색상 조화 방식 선택

5가지 버튼 중 원하는 조화 방식을 클릭합니다. 선택한 방식에 따라 팔레트가 즉시 다시 생성됩니다.

보색 유사색 삼각 배색 분할 보색 단색조
3

팔레트 확인 및 복사

생성된 색상 카드에서 스와치를 클릭하거나 HEX/RGB/HSL 옆 복사 버튼을 눌러 원하는 값을 클립보드에 복사합니다. 기준색으로 사용한 카드에는 "기준색" 배지가 표시됩니다.

4

CSS 변수로 내보내기

하단 📤 CSS 변수로 내보내기 카드에서 --color-primary부터 순서대로 자동 생성된 CSS 변수 코드를 확인하고, 📋 CSS 변수 복사 버튼으로 바로 복사해 스타일시트에 붙여넣습니다.

색상 조화 방식별 설명

방식구성느낌
보색기준색 + H+180°강한 대비, 생동감
유사색기준색, H±30°자연스럽고 편안함
삼각 배색기준색, H+120°, H+240°균형 잡힌 대비와 다채로움
분할 보색기준색, H+150°, H+210°보색만큼 강하지 않은 대비
단색조동일 H, 명도(L) 5단계(20/35/50/65/80%)통일감 있는 단색 그러데이션

기준색 #7B6CFF 예시

#7B6CFF
#F0FF6C (보색)

CSS 변수 출력 예시

:root { --color-primary: #7B6CFF; --color-secondary: #F0FF6C; }
⚠️ 참고: "유사색"과 "단색조"을 헷갈리기 쉬운데, 유사색은 색상(H)만 조금씩 다르고 채도·명도는 동일하게 유지하는 반면, 단색조은 색상(H)은 완전히 고정하고 명도(L)만 단계적으로 바꿉니다. 웹사이트 배경/텍스트처럼 톤을 통일해야 할 때는 단색조을, 포인트 컬러를 다양화하고 싶을 때는 유사색을 활용하세요.

활용 예시

🎨
브랜드 컬러 확장
메인 브랜드 컬러 하나로 보조색, 강조색을 자동 생성해 디자인 시스템의 색상 팔레트를 빠르게 구성합니다.
💻
CSS 변수 초기 세팅
새 프로젝트 시작 시 CSS 변수 내보내기로 :root 컬러 토큰을 즉시 만들어 스타일시트에 붙여넣습니다.
📊
차트/그래프 배색
삼각 배색나 분할 보색으로 데이터 시각화에 쓸 구분되는 색상 세트를 빠르게 생성합니다.
🎓
색채 이론 학습
색상환에서 보색, 삼각 배색 등이 실제로 어떤 색 조합을 만드는지 직접 입력해보며 학습합니다.
🔒 PaletteGen은 모든 색상 계산이 내 PC 브라우저에서만 실행됩니다. 입력한 색상이 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. 색상 팔레트 생성기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 만든 팔레트는 어떻게 활용하나요?

팔레트의 각 색상 코드를 복사해 디자인 도구나 CSS에 바로 사용할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

색상 1개로 보색, 유사색, 삼각 배색 등 조화로운 팔레트를 생성해보세요.
CSS 변수로 바로 내보내 프로젝트에 사용할 수 있습니다.
