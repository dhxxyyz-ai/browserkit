TextTools 사용법 완전 가이드

2026년 6월 18일

TextTools는 글자수 세기, 공백 정리, 대소문자 변환, 중복 제거까지 텍스트 작업을 브라우저에서 바로 처리하는 무료 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 입력한 텍스트가 외부 서버로 전송되지 않습니다.

주요 기능 (탭 4개)

📊
글자수 세기
전체 글자, 공백 제외, 단어 수, 줄 수, UTF-8 바이트, 문장 수를 실시간으로 표시합니다.
🧹
공백/줄바꿈 정리
연속 공백·줄바꿈 단일화, 앞뒤 공백 제거, 각 줄 공백 제거, 전체 제거 6가지 방식을 지원합니다.
🔤
대소문자 변환
UPPER, lower, Capitalize, camelCase, snake_case, kebab-case, PascalCase 7가지로 변환합니다.
❌
중복 제거
중복 줄, 빈 줄, 또는 둘 다 제거합니다. 제거된 줄 수도 함께 표시됩니다.

기본 사용법

1

탭 선택

화면 상단의 탭 버튼 중 원하는 기능을 선택합니다. 글자수 세기, 공백/줄바꿈 정리, 대소문자 변환, 중복 제거 4가지를 제공합니다.

2

텍스트 입력 또는 붙여넣기

왼쪽 입력 영역에 텍스트를 직접 입력하거나 붙여넣습니다. 글자수 세기 탭은 입력 즉시 결과가 실시간으로 갱신됩니다.

3

방식 선택 및 결과 복사

정리·변환·제거 탭에서는 원하는 방식 버튼을 클릭하면 오른쪽에 결과가 표시됩니다. 📋 결과 복사 버튼으로 클립보드에 복사하거나, ⇄ 결과→입력 버튼으로 결과를 다시 입력 영역에 가져올 수 있습니다.

탭별 상세 가이드

📊 글자수 세기

텍스트를 입력하면 6개 항목을 실시간으로 분석합니다. 블로그 글, 유튜브 설명란, SNS 게시물 작성 시 글자 수 제한을 확인하는 데 유용합니다.

항목설명
전체 글자공백 포함 전체 문자 수
공백 제외공백·탭·줄바꿈을 제외한 순수 문자 수
단어 수공백으로 구분된 단어 수
줄 수줄바꿈 기준 줄 수
바이트 (UTF-8)한글 3바이트, 영문 1바이트 기준 용량
문장 수. ! ? 。 기준 문장 수

🧹 공백/줄바꿈 정리

복사한 텍스트에 불필요한 공백이나 빈 줄이 많을 때 한 번에 정리할 수 있습니다.

버튼동작
연속 공백 → 단일여러 개의 공백을 하나로 줄임
연속 줄바꿈 → 단일여러 개의 빈 줄을 하나로 줄임
앞뒤 공백 제거 (trim)텍스트 전체의 앞뒤 공백 제거
각 줄 앞뒤 공백 제거줄마다 앞뒤 공백 개별 제거
모든 공백 제거스페이스 전체 삭제
모든 줄바꿈 제거줄바꿈 전체 삭제, 한 줄로 합침

🔤 대소문자 변환

개발 작업에서 변수명 형식을 바꿀 때나 영문 텍스트의 대소문자를 일괄 변경할 때 유용합니다.

방식입력 예시결과
UPPERhello worldHELLO WORLD
lowerHello Worldhello world
Capitalizehello worldHello World
camelCasehello worldhelloWorld
snake_casehello worldhello_world
kebab-casehello worldhello-world
PascalCasehello worldHelloWorld

❌ 중복 제거

키워드 목록, 주소 목록 등에서 중복된 항목을 빠르게 제거할 수 있습니다.

버튼동작
중복 줄 제거동일한 내용의 줄을 하나만 남김 (순서 유지)
빈 줄 제거내용이 없는 줄을 모두 삭제
중복+빈 줄 모두 제거두 가지를 동시에 적용
💡 TextTools는 모든 처리가 브라우저 내에서만 이루어집니다. 입력한 텍스트가 외부 서버로 전송되지 않아 개인정보나 기밀 문서도 안전하게 처리할 수 있습니다. 설치나 회원가입 없이 바로 사용할 수 있습니다.

대소문자 변환, 중복 제거, 공백 정리가 필요할 때 TextTools를 사용하세요.
복잡한 텍스트 가공 작업을 클릭 한 번으로 처리합니다.
