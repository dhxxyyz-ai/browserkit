이미지 보정 사용법 완전 가이드

2026년 6월 22일

ImageBright는 이미지의 밝기, 대비, 채도, 색온도, 샤프니스를 슬라이더로 실시간 조절하는 무료 온라인 이미지 보정 도구입니다. 사진 편집 앱 없이 브라우저에서 바로 보정할 수 있으며, 6가지 빠른 프리셋으로 한 번에 원하는 느낌을 낼 수도 있습니다. 모든 처리가 브라우저 내에서만 이루어지므로 이미지가 외부 서버로 전송되지 않습니다.

주요 기능

🎨
5가지 보정 슬라이더
밝기, 대비, 채도, 색온도, 샤프니스를 슬라이더로 실시간 조절합니다. 값을 바꾸는 즉시 결과가 표시됩니다.
⚡
6가지 빠른 프리셋
선명하게, 따뜻하게, 차갑게, 밝게, 어둡게, 흑백 중 하나를 클릭하면 슬라이더가 자동으로 설정됩니다.
📷
원본 / 결과 비교
원본과 보정 결과를 좌우로 나란히 표시합니다. 체커보드 배경으로 투명 픽셀을 쉽게 확인할 수 있습니다.
⬇
JPG / PNG 저장
보정된 이미지를 JPG(고화질 0.92) 또는 PNG(무손실)로 다운로드합니다.

기본 사용법

1

이미지 업로드

업로드 존을 클릭하거나 이미지를 드래그해 불러옵니다. JPG, PNG, WEBP, GIF 형식을 지원합니다.

2

슬라이더 조절 또는 프리셋 선택

슬라이더를 좌우로 움직이거나 빠른 프리셋 버튼을 클릭합니다. 오른쪽 결과 패널에 변화가 즉시 반영됩니다.

3

저장

JPG 저장 또는 PNG 저장 버튼으로 보정된 이미지를 다운로드합니다.

슬라이더범위효과
☀️ 밝기 -100 ~ +100 모든 픽셀의 R, G, B 값을 일정량 올리거나 내립니다. +값은 밝게, -값은 어둡게 만듭니다.
◐ 대비 -100 ~ +100 밝은 부분은 더 밝게, 어두운 부분은 더 어둡게 만들어 명암 차이를 강조합니다. -값은 대비를 줄여 뿌옇게 만듭니다.
🌈 채도 -100 ~ +100 색의 선명도를 조절합니다. +값은 색이 진해지고, -값은 색이 빠지며, -100이면 흑백이 됩니다.
🌡️ 색온도 -100 ~ +100 +값은 붉은 계열(따뜻함), -값은 파란 계열(차가움)로 색조가 변합니다. 실내 조명 보정에 유용합니다.
📷 샤프니스 0 ~ 100 언샤프 마스크 알고리즘으로 경계선을 선명하게 만듭니다. 과도하면 노이즈가 생길 수 있습니다.

빠른 프리셋

슬라이더를 일일이 조절하지 않아도 프리셋 버튼 하나로 원하는 분위기를 즉시 적용할 수 있습니다.

프리셋주요 효과적합한 상황

🧡 따뜻하게밝기 +5, 색온도 +40실내 조명 보정, 음식 사진, 따뜻한 분위기

⚫ 흑백채도 -100, 대비 +20, 샤프니스 10흑백 사진 변환, 감성적인 연출

활용 예시

🍴
음식 사진 보정
따뜻하게 프리셋 또는 채도 +20, 색온도 +20으로 음식의 색감을 더 맛있어 보이게 만듭니다.
🏔️
풍경 사진 강화
선명하게 프리셋 또는 대비 +15, 채도 +20으로 하늘과 녹음을 더 선명하게 표현합니다.
📊
프레젠테이션 이미지
밝기 +15, 대비 +10으로 빔 프로젝터에서 선명하게 보일 수 있도록 이미지를 밝게 보정합니다.
👥
인물 사진 보정
밝기 +10, 대비 -5, 채도 +5로 피부 톤을 자연스럽게 밝히고 샤프니스로 눈매를 선명하게 표현합니다.
📦
제품 사진 보정
선명하게 프리셋 또는 대비 +15, 샤프니스 +30으로 제품의 디테일과 질감을 강조합니다.
🌊
흑백 사진 변환
흑백 프리셋 하나로 채도를 완전히 제거하고 대비를 높여 감성적인 흑백 사진으로 변환합니다.

저장 형식 선택 가이드

형식특징추천 용도
JPG 저장 압축률 높음, 파일 크기 작음 (품질 0.92 적용) SNS 업로드, 이메일 첨부, 웹 사용
PNG 저장 무손실 압축, 파일 크기 큼, 투명 배경 지원 인쇄, 고화질 보존, 투명 배경 필요 시

기술 원리

ImageBright는 Canvas API의 getImageData()로 이미지의 전체 픽셀 배열을 읽어와 각 픽셀의 R, G, B 값을 직접 계산합니다. 외부 이미지 편집 라이브러리 없이 순수 JavaScript만으로 구현되어 있습니다.

보정 항목알고리즘
밝기모든 픽셀의 R, G, B에 고정값을 더하거나 뺍니다
대비중간점(128) 기준으로 (259×(c+255))/(255×(259-c)) 팩터를 곱합니다
채도RGB → HSL 변환 → S(채도) 값 조절 → RGB 역변환
색온도R 채널 값을 올리고(따뜻) B 채널 값을 내리거나(차갑게), 반대로 적용합니다
샤프니스4-이웃 언샤프 마스크 컨볼루션으로 경계 픽셀을 강조합니다

주의사항

항목내용
샤프니스 과도 적용샤프니스를 너무 높이면 노이즈가 생기거나 가장자리가 과하게 강조될 수 있습니다. 20~40 범위를 권장합니다.
대용량 이미지픽셀 단위 처리 특성상 매우 큰 이미지는 처리 시간이 길어질 수 있습니다. 자동으로 2000px 이하로 리샘플링됩니다.
GIF 애니메이션GIF 업로드 시 첫 번째 프레임만 처리됩니다. 애니메이션은 보존되지 않습니다.
JPG 손실JPG 저장은 압축 손실이 있습니다. 원본 화질 보존이 필요하면 PNG로 저장하세요.
✨ ImageBright는 모든 처리가 브라우저 내에서만 이루어집니다. 업로드한 이미지가 외부 서버로 전송되지 않으므로, 개인 사진이나 민감한 이미지도 안전하게 보정할 수 있습니다.

자주 묻는 질문

Q. 이미지 보정 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 보정하면 원본 이미지가 훼손되나요?

아니요. 원본 파일은 그대로 두고 보정된 결과물을 새 파일로 다운로드하는 방식이라 원본이 변경되지 않습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

어둡게 찍힌 사진, 색이 바랜 이미지를 밝기·대비·채도 슬라이더로 보정하세요.
6가지 프리셋으로 클릭 한 번에 분위기를 바꿀 수 있습니다.
