URL 인코더 사용법 완전 가이드

2026년 7월 9일

URLEncode는 텍스트를 URL 인코딩/디코딩하고, URL의 쿼리 파라미터를 표 형태로 파싱하거나 키-값을 입력해 쿼리 URL을 조립하는 무료 온라인 도구입니다. 한글이나 특수문자가 섞인 텍스트를 URL에 안전하게 넣거나, 복잡한 쿼리스트링을 한눈에 읽고 싶을 때 바로 사용할 수 있습니다. 모든 처리가 브라우저 내에서만 이루어지므로 텍스트가 외부 서버로 전송되지 않습니다.

주요 기능

🔐
URL 인코딩/디코딩
encodeURIComponent와 encodeURI 두 방식 중 선택해 텍스트를 인코딩하거나 디코딩합니다.
🔍
쿼리 파라미터 파싱
전체 URL이나 쿼리 문자열을 붙여넣으면 각 파라미터를 키-값 표로 정리해 보여줍니다.
🔧
쿼리 빌더
기본 URL과 키-값을 입력하면 인코딩까지 자동으로 처리된 완성 URL을 조립합니다.
🔒
완전 로컬 처리
모든 변환이 브라우저 안에서 실행됩니다. 텍스트가 서버로 전송되지 않아 비공개 데이터도 안심하고 사용할 수 있습니다.

탭 구성

🔐 인코딩/디코딩
🔍 쿼리 파싱
🔧 쿼리 빌더

인코딩/디코딩 탭에서는 텍스트 조각을 변환하고, 쿼리 파싱 탭에서는 완성된 URL을 분석하고, 쿼리 빌더 탭에서는 새 URL을 조립합니다.

인코딩/디코딩 사용법

1

인코딩 방식 선택

encodeURIComponent 또는 encodeURI 중 하나를 선택합니다. 아래 인코딩 방식 비교 표를 참고해 상황에 맞는 방식을 고르세요.

2

텍스트 입력

왼쪽 입력창에 인코딩할 텍스트 또는 디코딩할 URL 인코딩 문자열을 입력합니다.

3

결과 확인 및 복사

📋 결과 복사 버튼으로 클립보드에 복사하거나, ⇄ 입출력 교환 버튼으로 결과를 다시 입력값으로 옮겨 반대로 변환할 수 있습니다.

인코딩 방식 비교

방식인코딩 범위사용 상황
encodeURIComponent & = ? / : # ; , + 등 URL 구분자까지 모두 인코딩 쿼리 파라미터 값, 폼 데이터 등 URL의 한 조각을 인코딩할 때
encodeURI : / ? # & = 등 URL 구조에 필요한 구분자는 유지 완전한 URL 전체(경로+쿼리)를 통째로 인코딩할 때

인코딩 결과 예시

입력
https://example.com/검색?q=hello world
encodeURIComponent
https%3A%2F%2Fexample.com%2F%EA%B2%80%EC%83%89%3Fq%3Dhello%20world
입력
https://example.com/검색?q=hello world
encodeURI
https://example.com/%EA%B2%80%EC%83%89?q=hello%20world

encodeURI는 :, /, ?, = 같은 URL 구조 문자를 그대로 남기고, 한글이나 공백처럼 URL에 그대로 쓸 수 없는 문자만 인코딩합니다.

쿼리 파싱 사용법

1

URL 또는 쿼리 문자열 붙여넣기

전체 URL(https://...?a=1&b=2)이나 쿼리 문자열(a=1&b=2)만 붙여넣어도 됩니다. ? 앞의 도메인·경로 부분은 자동으로 제외하고 분석합니다.

2

파라미터 표 확인

각 파라미터가 키-값 표로 정리되어 표시됩니다. + 기호는 공백으로 자동 디코딩되고, 값이 없는 파라미터도 빈 값으로 표시됩니다.

3

값 복사 또는 JSON 내보내기

각 행의 복사 버튼으로 개별 값을 복사하거나, 📋 JSON으로 복사 버튼으로 전체 파라미터를 JSON 객체 형태로 한 번에 복사할 수 있습니다.

쿼리 빌더 사용법

1

기본 URL 입력 (선택사항)

도메인과 경로만 입력합니다. 비워두면 쿼리 문자열(?key=value&...)만 조립됩니다.

2

키-값 입력

+ 파라미터 추가 버튼으로 행을 늘리고, 각 행에 키와 값을 입력합니다. 값은 자동으로 URL 인코딩되어 조립됩니다.

3

URL 복사

하단에 조립된 URL이 실시간으로 표시됩니다. 📋 URL 복사 버튼으로 바로 사용할 수 있습니다.

⚠️ 참고: 쿼리 빌더는 URLSearchParams를 사용해 값을 자동으로 인코딩합니다. 이미 인코딩된 값을 다시 입력하면 이중으로 인코딩될 수 있으니, 원본(디코딩된) 값을 그대로 입력하세요.

활용 예시

🔗
공유 링크 파라미터 확인
친구가 보낸 긴 URL에 어떤 추적 파라미터나 옵션이 들어있는지 쿼리 파싱으로 빠르게 확인합니다.
📡
API 테스트 URL 조립
쿼리 빌더로 여러 파라미터가 포함된 API 요청 URL을 실수 없이 조립해 Postman이나 브라우저에서 바로 테스트합니다.
🇰️
다국어 URL 인코딩
한글, 일본어 등이 포함된 경로나 검색어를 URL에 안전하게 넣기 위해 인코딩합니다.
🐛
깨진 URL 디버깅
이중 인코딩되었거나 깨진 URL을 디코딩해 원래 값이 무엇이었는지 역추적합니다.

기술 원리

기능사용 API특징
인코딩/디코딩encodeURIComponent / encodeURI / decodeURIComponent / decodeURI브라우저 내장 함수, 추가 라이브러리 없음
쿼리 파싱URLSearchParams중복 키, 빈 값, + 공백 변환을 표준에 맞게 자동 처리
쿼리 빌더URLSearchParams.append + toString()입력한 값을 자동으로 인코딩해 조립

외부 라이브러리나 CDN 없이 브라우저 내장 API만으로 동작하며, 모든 변환이 내 PC 브라우저 안에서 실행됩니다.

🔒 URLEncode는 모든 변환이 내 PC 브라우저에서만 실행됩니다. 입력한 텍스트나 URL이 외부 서버로 전송되지 않아 비공개 링크나 내부 API 주소도 안심하고 사용할 수 있습니다.

자주 묻는 질문

Q. URL 인코더 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 한글이 포함된 URL도 변환되나요?

네, 한글 등 비ASCII 문자를 UTF-8 기반 퍼센트 인코딩으로 변환하고 다시 복원할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

텍스트를 URL 인코딩/디코딩하고 쿼리 파라미터를 파싱·조립해보세요.
복잡한 URL도 표로 한눈에 파악할 수 있습니다.
