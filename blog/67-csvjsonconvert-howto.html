CSV ↔ JSON 변환기 사용법 완전 가이드

2026년 7월 12일

CSVJSONConvert는 CSV 데이터를 JSON 배열로, JSON 배열을 다시 CSV로 즉시 변환해주는 무료 온라인 도구입니다. 텍스트를 직접 붙여넣거나 파일을 업로드하면 자체 구현한 파서가 큰따옴표로 감싼 필드 안의 쉼표·줄바꿈·이스케이프된 따옴표까지 정확히 처리하며, 변환 결과는 표로 미리보기할 수 있어 데이터가 의도대로 변환됐는지 바로 확인할 수 있습니다. 모든 처리는 브라우저에서만 이루어집니다.

주요 기능

🔄
양방향 변환
CSV → JSON, JSON → CSV 두 방향 모두 버튼 한 번으로 전환해 사용할 수 있습니다.
📋
붙여넣기·업로드 지원
텍스트를 직접 붙여넣거나 .csv, .json 파일을 드래그해 바로 불러올 수 있습니다.
📊
표 미리보기
변환 결과를 표로 렌더링해 데이터가 올바르게 파싱됐는지 한눈에 확인합니다.
🔒
완전 로컬 처리
모든 변환이 브라우저 안에서 실행됩니다. 데이터가 서버로 전송되지 않습니다.

사용법

1

변환 방향 선택

상단에서 CSV → JSON 또는 JSON → CSV 중 원하는 방향을 선택합니다. 방향에 따라 입력·출력 라벨과 안내 문구가 자동으로 바뀝니다.

2

데이터 입력

왼쪽 입력창에 CSV 또는 JSON 데이터를 직접 붙여넣거나, 업로드 영역을 클릭해 .csv/.json 파일을 선택합니다. 파일을 업로드하면 확장자에 맞춰 변환 방향도 자동으로 전환됩니다.

3

구분자·헤더 옵션 설정

구분자는 쉼표, 탭, 세미콜론 중 선택할 수 있고, 첫 행을 헤더로 사용 옵션을 켜면 첫 번째 행을 JSON의 키(또는 CSV의 열 이름)로 사용합니다.

4

변환 및 결과 확인

🔄 변환하기 버튼을 누르면 결과가 오른쪽 창과 아래 표 미리보기에 함께 표시됩니다. 📋 결과 복사로 클립보드에 복사하거나 ⬇ 파일 다운로드로 저장할 수 있습니다.

⚠️ 참고: 자체 구현한 경량 CSV 파서를 사용합니다. 큰따옴표로 감싼 필드 안의 쉼표·줄바꿈·이스케이프된 따옴표("")는 정확히 처리하지만, 필드마다 서로 다른 구분자를 섞어 쓰거나 표준을 크게 벗어난 CSV는 결과가 예상과 다를 수 있습니다. JSON → CSV 변환 시 최상위 값은 반드시 배열이어야 하며, 변환 후에는 표 미리보기로 데이터를 한 번 더 확인하는 것을 권장합니다.

지원 옵션

옵션설명
변환 방향CSV → JSON, JSON → CSV
구분자쉼표(,), 탭, 세미콜론(;)
헤더 사용첫 행을 키/열 이름으로 사용할지 여부
파일 업로드.csv, .json, .txt 드래그 앤 드롭 또는 클릭 업로드

활용 예시

📈
스프레드시트 데이터 API 연동
엑셀·구글시트에서 내보낸 CSV를 API 테스트용 JSON으로 빠르게 바꿉니다.
🗃️
데이터베이스 마이그레이션
DB 덤프 결과를 JSON으로 변환해 스크립트나 목데이터로 활용합니다.
📝
JSON 응답을 표로 정리
API 응답 JSON을 CSV로 바꿔 엑셀에서 열어보고 정리합니다.
🔍
데이터 검증
변환 전후 표 미리보기로 필드 개수와 값이 올바른지 빠르게 검증합니다.
🔒 CSVJSONConvert는 모든 변환이 내 PC 브라우저에서만 실행됩니다. 입력한 데이터가 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. CSV ↔ JSON 변환기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 용량이 큰 파일도 변환되나요?

브라우저에서 처리 가능한 범위라면 문제없이 변환됩니다. 매우 큰 파일은 기기 성능에 따라 시간이 걸릴 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
