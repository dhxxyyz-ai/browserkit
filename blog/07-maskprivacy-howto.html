개인정보 마스킹 사용법 완전 가이드

2026년 6월 10일

MaskPrivacy는 이미지 속 개인정보를 브라우저에서 자동으로 감지·마스킹해주는 무료 온라인 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 개인정보 유출 걱정이 없습니다.

주요 기능

🔍
자동 개인정보 탐지
주민등록번호, 전화번호, 이메일, 계좌번호, 주소를 OCR로 자동 탐지합니다.
✏️
수동 마스킹
드래그(모바일은 두 번 탭)로 원하는 영역을 직접 지정해 마스킹할 수 있습니다.
⚙️
마스킹 방식 선택
주민번호·전화번호는 전체 또는 부분 마스킹을 선택할 수 있습니다.
📥
PNG 다운로드
마스킹 완료된 이미지를 즉시 PNG로 다운로드할 수 있습니다.

기본 사용법

1

이미지 업로드

업로드 영역에 이미지를 드래그하거나 클릭해서 파일을 선택합니다. PNG, JPG, WEBP 형식을 지원합니다.

2

자동 탐지 대기

업로드 후 OCR 엔진이 이미지를 분석합니다. 보통 10~30초 정도 소요됩니다.

3

탐지 결과 확인

탐지된 개인정보 항목(주민등록번호·전화번호·이메일·계좌번호·주소)이 목록으로 표시됩니다. 각 항목 옆의 토글로 마스킹 여부를 개별적으로 조정할 수 있고, 드롭다운으로 항목별 마스킹 스타일(검정/모자이크/블러)을 바꿀 수 있습니다.

4

마스킹 방식 선택

주민번호는 전체 가리기 / 뒷자리 전체 / 뒷자리 6자리 중 선택할 수 있습니다. 전화번호는 전체 / 뒷 8자리 / 뒷 4자리 중 선택 가능합니다.

5

수동 마스킹 보완

자동으로 탐지되지 않은 영역은 마스킹 결과 이미지에서 직접 가릴 수 있습니다. PC에서는 마우스로 드래그하고, 모바일에서는 시작점과 끝점을 두 번 탭하면 됩니다. 툴바에서 검정·모자이크·블러 스타일을 고를 수 있고, 되돌리기 버튼으로 마지막 수동 마스킹을 취소할 수 있습니다(PC는 Ctrl+Z도 가능).

6

다운로드

마스킹 완료 후 다운로드 버튼을 클릭하면 PNG 파일로 저장됩니다.

자주 묻는 질문

Q. 개인정보 마스킹 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 자동 탐지가 놓친 개인정보는 어떻게 처리하나요?

자동 탐지 결과를 확인한 뒤 수동으로 영역을 지정해 추가로 가릴 수 있습니다. 중요한 문서는 저장 전에 반드시 직접 검수하는 것을 권장합니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

신분증·계약서·진단서 이미지를 브라우저에서 바로 마스킹하세요.
파일이 서버로 전송되지 않아 민감한 문서도 안심하고 처리할 수 있습니다.
