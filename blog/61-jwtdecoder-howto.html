JWT 디코더 사용법 완전 가이드

2026년 7월 10일

JWTDecoder는 JWT(JSON Web Token)를 붙여넣으면 헤더와 페이로드를 즉시 디코딩해 보여주는 무료 온라인 도구입니다. Base64Url로 인코딩된 JWT의 각 부분을 사람이 읽을 수 있는 JSON으로 풀어서 보여주고, exp·iat·nbf 같은 시간 클레임을 실제 날짜로 변환해 표시합니다. 서명 검증은 수행하지 않으며, 모든 디코딩은 브라우저 안에서만 처리됩니다.

주요 기능

🔍
헤더/페이로드 즉시 디코딩
토큰을 붙여넣는 즉시 헤더와 페이로드를 색상 구분된 JSON으로 보여줍니다.
⏱️
만료 시각 자동 변환
exp, iat, nbf 유닉스 타임스탬프를 날짜로 변환하고, 만료 여부를 배지로 표시합니다.
🎨
3-part 색상 구분 프리뷰
헤더·페이로드·서명을 jwt.io와 같은 방식으로 색상 구분해 원본 토큰을 한눈에 보여줍니다.
🔒
완전 로컬 처리
모든 디코딩이 브라우저 안에서 실행됩니다. 토큰이 서버로 전송되지 않습니다.

사용법

1

JWT 토큰 붙여넣기

입력창에 헤더.페이로드.서명 형태의 JWT 토큰을 붙여넣습니다. 테스트해보고 싶다면 📋 예시 토큰 채우기 버튼을 사용합니다.

2

디코딩 결과와 만료 시각 확인

HEADER, PAYLOAD 카드에서 실제 JSON 내용을 확인하고, 상단 표준 시간 클레임 카드에서 exp가 아직 유효한지 만료됐는지 배지로 바로 확인합니다.

3

필요하면 JSON 복사

HEADER, PAYLOAD 카드 상단의 복사 버튼으로 각 JSON을 클립보드에 복사해 다른 도구나 코드에 바로 붙여넣을 수 있습니다.

⚠️ 참고: JWTDecoder는 토큰을 디코딩만 합니다 — 서명이 유효한지 검증하지 않습니다. Base64Url로 인코딩된 헤더와 페이로드는 암호화된 것이 아니라 누구나 디코딩해 읽을 수 있으므로, 비밀번호나 신용카드 번호 같은 민감한 정보를 JWT 페이로드에 직접 담지 마세요. 서명 검증이 필요하다면 발급자의 비밀키(secret) 또는 공개키를 아는 서버 측 라이브러리를 사용해야 합니다.

주요 표준 클레임

클레임의미이 도구에서 표시하는 방식
iat발급 시각(Issued At)유닉스 타임스탬프를 날짜/시간으로 변환
nbf이 시각 이전에는 무효(Not Before)유닉스 타임스탬프를 날짜/시간으로 변환
exp만료 시각(Expiration)날짜 변환 + 현재 시각과 비교한 유효/만료 배지
alg서명 알고리즘(헤더에 위치)HEADER JSON 카드에 원본 그대로 표시

활용 예시

🐛
API 인증 디버깅
401/403 오류가 날 때 토큰의 만료 시각이나 클레임 값을 빠르게 확인합니다.
🧪
개발 중 토큰 검사
로그인 API가 반환한 access token/refresh token의 내용을 즉시 확인합니다.
📚
JWT 구조 학습
헤더·페이로드·서명 3부분 구조를 실제 토큰으로 눈으로 확인하며 익힙니다.
🔐
만료 정책 점검
발급된 토큰의 exp 값이 의도한 만료 시간과 일치하는지 확인합니다.
🔒 JWTDecoder는 모든 디코딩이 내 PC 브라우저에서만 실행됩니다. 토큰이 외부 서버로 전송되지 않습니다.

JWT 토큰을 붙여넣고 헤더와 페이로드를 바로 확인해보세요.
만료 시각까지 한눈에 파악할 수 있습니다.
