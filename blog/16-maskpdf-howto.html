PDF 마스킹 사용법 완전 가이드

2026년 6월 13일

MaskPDF는 PDF 속 개인정보를 브라우저에서 자동으로 감지·마스킹해주는 무료 온라인 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 PDF 파일이 외부 서버로 전송되지 않습니다.

주요 기능

🔍
자동 개인정보 탐지
주민번호, 전화번호, 이메일, 계좌번호, 주소를 OCR로 자동 탐지합니다.
📋
탐지 결과 요약
페이지별 탐지 건수를 요약으로 표시하고, 클릭하면 해당 페이지로 이동합니다.
✏️
수동 마스킹
드래그(모바일은 두 번 탭)로 원하는 영역을 직접 지정하고, 검정·모자이크·블러 스타일을 선택할 수 있습니다.
⚙️
마스킹 방식 선택
주민번호·전화번호는 전체 또는 부분 마스킹을 선택할 수 있습니다.
📄
다중 페이지 지원
여러 페이지 PDF를 한 번에 처리하고 페이지별로 개별 확인합니다.
📥
PDF 다운로드
마스킹 완료된 파일을 즉시 PDF로 다운로드할 수 있습니다.

기본 사용법

1

PDF 파일 업로드

업로드 영역에 PDF 파일을 드래그하거나 클릭해서 파일을 선택합니다. 20페이지 이하를 권장합니다.

2

페이지 렌더링 및 OCR 분석 대기

PDF.js로 전체 페이지를 이미지로 변환한 뒤, OCR 엔진이 페이지별로 순차 분석합니다. 진행 상황은 Progress Bar로 확인할 수 있습니다.

3

탐지 결과 요약 확인

분석이 완료되면 개인정보가 탐지된 페이지 목록이 요약으로 표시됩니다. 항목을 클릭하면 해당 페이지로 바로 이동합니다. 각 탐지 항목 옆의 드롭다운으로 마스킹 스타일(검정/모자이크/블러)을 개별적으로 바꿀 수 있고, 삭제(✕) 버튼으로 제거할 수도 있습니다.

4

마스킹 방식 선택

주민번호는 전체 가리기 / 뒷자리 전체 / 뒷자리 6자리 중 선택할 수 있습니다. 전화번호는 전체 / 뒷 8자리 / 뒷 4자리 중 선택 가능합니다. 변경 시 전체 페이지에 일괄 적용됩니다.

5

수동 마스킹 보완

자동으로 탐지되지 않은 영역은 마스킹 결과 이미지에서 직접 가릴 수 있습니다. PC에서는 마우스로 드래그하고, 모바일에서는 시작점과 끝점을 두 번 탭하면 됩니다. 툴바에서 검정·모자이크·블러 스타일을 고를 수 있고, 되돌리기 버튼(PC는 Ctrl+Z도 가능)으로 현재 페이지의 마지막 수동 마스킹을 취소할 수 있습니다. 수동 마스킹 영역도 탐지 목록에 추가됩니다.

6

페이지 이동 및 전체 확인

이전/다음 버튼으로 페이지를 이동하며 모든 페이지의 마스킹 결과를 검토합니다.

7

PDF 다운로드

마스킹 완료 후 다운로드 버튼을 클릭하면 maskpdf_result.pdf 파일로 저장됩니다.

자주 묻는 질문

Q. PDF 마스킹 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 마스킹한 부분을 나중에 다시 복구할 수 있나요?

저장된 결과 파일에는 해당 영역이 가려진 상태로 기록되어 일반적인 방법으로는 원본 내용을 볼 수 없습니다. 원본 파일은 별도로 보관하세요.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

PDF 파일도 업로드 없이 브라우저에서 직접 처리합니다.
10MB 이하 PDF라면 수초 안에 마스킹이 완료됩니다.
