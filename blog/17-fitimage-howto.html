이미지 변환 사용법 완전 가이드

2026년 6월 16일 (2026년 7월 4일 수정)

FitImage는 이미지 크기 조정, 형식 변환, 용량 압축을 브라우저에서 바로 처리해주는 무료 온라인 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 이미지 파일이 외부 서버로 전송되지 않습니다.

주요 기능

📐
크기 조정
가로/세로 px를 직접 입력하거나 단축 버튼으로 빠르게 조정합니다. 비율 유지 옵션을 지원합니다.
🔄
형식 변환
PNG, JPG, WEBP 중 원하는 형식으로 변환합니다. 투명 배경은 JPG/WEBP 변환 시 자동으로 흰색으로 채워집니다.
📦
용량 압축
품질 슬라이더로 파일 크기를 줄입니다. 압축 전후 용량과 감소율을 실시간으로 확인할 수 있습니다.
🖥️
완전 로컬 처리
이미지가 서버로 전송되지 않아 민감한 사진도 안심하고 처리할 수 있습니다.
👁️
실시간 미리보기
원본과 결과를 나란히 비교하며 해상도와 예상 파일 크기를 바로 확인할 수 있습니다.
📥
즉시 다운로드
처리 완료된 이미지를 바로 다운로드할 수 있습니다. 탭별로 파일명이 자동 생성됩니다.

기본 사용법

1

이미지 업로드

업로드 영역에 이미지를 드래그하거나 클릭해서 파일을 선택합니다. PNG, JPG, WEBP, GIF 형식을 지원합니다.

2

기능 탭 선택

📐 크기 조정 / 🔄 형식 변환 / 📦 용량 압축 중 원하는 기능 탭을 선택합니다. 탭을 전환하면 해당 옵션 영역이 나타납니다.

3

옵션 설정

크기 조정은 목표 px 또는 단축 버튼으로, 형식 변환은 출력 형식 선택으로, 용량 압축은 품질 슬라이더로 각각 설정합니다.

4

미리보기 확인

원본과 결과를 나란히 비교하며 해상도와 예상 파일 크기를 확인합니다. 옵션을 바꿀 때마다 결과가 즉시 갱신됩니다.

5

이미지 다운로드

다운로드 버튼을 클릭하면 처리된 이미지가 저장됩니다. 파일명은 탭에 따라 자동 생성됩니다 (예: fitimage_800x450.png, fitimage_converted.jpg, fitimage_compressed.webp).

📐 크기 조정 상세 안내

가로/세로 px 입력 필드에 원하는 크기를 입력합니다. 비율 유지 체크박스를 선택하면 가로를 입력할 때 세로가 자동으로 계산됩니다. 자주 쓰는 크기는 단축 버튼으로 빠르게 설정할 수 있습니다.

단축 버튼설명
50%원본 크기의 절반으로 축소
75%원본 크기의 75%로 축소
1280px가로 1280px (Full HD 기준)
800px가로 800px (블로그/SNS 이미지 기준)
640px가로 640px (모바일 최적화)

🔄 형식 변환 상세 안내

PNG, JPG, WEBP 중 원하는 출력 형식을 선택합니다. 용도에 따라 적합한 형식이 다릅니다.

형식특징권장 용도
PNG투명 배경 지원 / 무손실로고, 아이콘, 스크린샷
JPG파일 크기 작음 / 배경 흰색 변환사진, 일반 이미지
WEBP최신 형식 / 고압축 고화질웹 최적화 이미지

📦 용량 압축 상세 안내

품질 슬라이더(1~100%)로 출력 품질을 조정합니다. 수치가 낮을수록 파일 크기는 작아지지만 화질이 저하됩니다. 결과 영역에서 압축 전후 용량과 감소율을 실시간으로 확인할 수 있습니다.

단축 버튼품질설명
고화질90%화질 손실 최소화, 파일 크기 소폭 감소
표준75%화질과 용량의 균형 (일반적으로 권장)
최소50%파일 크기 최대 감소, 화질 저하 있음
💡 PNG는 무손실 형식이라 품질 슬라이더가 적용되지 않습니다. 용량을 줄이고 싶다면 형식 변환 탭에서 JPG 또는 WEBP로 변환한 뒤 압축하세요. GIF 파일은 업로드 시 첫 번째 프레임만 처리되므로 애니메이션이 손실됩니다. JPG/WEBP 변환 시 투명 배경은 자동으로 흰색으로 채워집니다.

자주 묻는 질문

Q. 이미지 변환 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 어떤 이미지 형식을 지원하나요?

JPG, PNG, WebP 등 주요 이미지 형식 간 변환을 지원하며, 크기 조정과 용량 압축도 함께 처리할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

SNS 업로드 전 크기를 줄이거나 JPEG↔PNG 변환이 필요할 때 사용하세요.
원본 화질을 유지하면서 파일 용량을 최대 80%까지 줄일 수 있습니다.
