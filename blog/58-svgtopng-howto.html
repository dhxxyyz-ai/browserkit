SVG → PNG 변환기 사용법 완전 가이드

2026년 7월 10일

SVGtoPNG는 SVG 파일을 업로드하거나 SVG 코드를 직접 붙여넣어 원하는 해상도의 PNG 이미지로 변환하는 무료 온라인 도구입니다. 너비·높이를 픽셀 단위로 지정하거나 1x~4x 배율 버튼으로 간편하게 해상도를 높일 수 있고, 투명·흰색·검정·사용자 지정 색상 중 원하는 배경을 선택할 수 있습니다. 모든 변환이 브라우저 내에서만 이루어지므로 SVG 내용이 외부 서버로 전송되지 않습니다.

주요 기능

📁
파일 업로드 / 코드 붙여넣기
.svg 파일을 드래그하거나, SVG 코드를 텍스트로 직접 붙여넣어 변환할 수 있습니다.
📏
해상도·배율 지정
너비·높이를 직접 입력하거나 1x~4x 배율 버튼으로 원하는 크기의 PNG를 만듭니다.
🎨
배경색 선택
투명·흰색·검정 중 선택하거나 색상 피커로 원하는 배경색을 직접 지정합니다.
🔒
완전 로컬 처리
모든 변환이 브라우저 안에서 실행됩니다. SVG 내용이 서버로 전송되지 않습니다.

사용법

1

SVG 업로드 또는 코드 붙여넣기

상단 탭에서 📁 파일 업로드를 선택해 .svg 파일을 드래그하거나, 📝 코드 붙여넣기 탭에서 SVG 코드를 직접 입력한 뒤 변환하기 버튼을 누릅니다.

2

출력 옵션 조정

너비·높이를 직접 입력하거나(비율 고정 체크 시 자동 계산), 1x~4x 배율 버튼으로 해상도를 높입니다. 배경은 투명·흰색·검정 중 선택하거나 색상 피커로 원하는 색을 지정합니다.

3

미리보기 확인 후 PNG 다운로드

결과 미리보기에서 실제 변환될 이미지를 확인한 뒤 ⬇ PNG 다운로드 버튼을 눌러 파일을 저장합니다. 옵션을 바꾸면 미리보기가 실시간으로 갱신됩니다.

⚠️ 참고: 외부 이미지·폰트를 <image> 태그나 @font-face로 참조하는 SVG는 브라우저 보안 정책(캔버스 오염 방지)상 변환이 제한되거나 해당 요소가 비어 보일 수 있습니다. 텍스트, 도형, 경로 등으로만 구성된 자체 완결형 SVG를 사용하면 가장 안정적으로 변환됩니다.

활용 예시

📄
문서·프레젠테이션 삽입
SVG를 지원하지 않는 프로그램(구버전 오피스, PDF 편집기 등)에 이미지로 삽입할 때 사용합니다.
📱
SNS·썸네일 이미지
SVG 로고나 아이콘을 SNS 프로필, 썸네일용 PNG로 변환합니다.
🖨️
고해상도 인쇄 자료
벡터 로고를 3x~4x 배율로 변환해 인쇄용 고해상도 PNG를 준비합니다.
🎨
디자인 툴 호환
SVG를 지원하지 않는 도구에서 벡터 아이콘을 PNG로 바꿔 활용합니다.
🔒 SVGtoPNG는 모든 변환이 내 PC 브라우저에서만 실행됩니다. SVG 내용이 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. SVG → PNG 변환기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 변환할 PNG의 해상도를 지정할 수 있나요?

네, 원하는 출력 크기를 지정해 선명한 PNG로 변환할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

SVG 파일이나 코드를 원하는 해상도의 PNG로 변환해보세요.
배율과 배경색까지 자유롭게 선택할 수 있습니다.
