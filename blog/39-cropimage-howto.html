CropImage 사용법 완전 가이드

2026년 7월 4일

CropImage는 이미지 자르기, 회전, 반전을 브라우저에서 바로 처리해주는 무료 온라인 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 이미지 파일이 외부 서버로 전송되지 않습니다.

주요 기능

✂️
이미지 자르기
이미지 위에서 드래그해 원하는 영역을 직접 선택합니다. 자유 비율 또는 프리셋 비율을 선택할 수 있습니다.
🪪
증명사진 비율
3:4 비율 단축 버튼으로 증명사진에 맞는 비율을 빠르게 선택할 수 있습니다.
🔄
회전
90° 시계 방향 또는 반시계 방향으로 회전합니다. 가로·세로 사진 방향을 바로 바꿀 수 있습니다.
↔️
반전
좌우 반전(거울 효과) 또는 상하 반전을 적용합니다.
🖥️
완전 로컬 처리
이미지가 서버로 전송되지 않아 민감한 사진도 안심하고 처리할 수 있습니다.
📥
즉시 다운로드
처리 완료된 이미지를 PNG 파일로 즉시 다운로드할 수 있습니다.

기본 사용법

1

이미지 업로드

업로드 영역에 이미지를 드래그하거나 클릭해서 파일을 선택합니다. JPG, PNG, WEBP, GIF 형식을 지원합니다.

2

기능 탭 선택

✂️ 자르기 또는 🔄 회전 / 반전 탭 중 원하는 기능을 선택합니다. 탭을 전환하면 해당 편집 영역이 나타납니다.

3

편집 적용

자르기 탭에서는 비율을 선택한 뒤 이미지 위에서 드래그로 영역을 지정하고 자르기 적용 버튼을 클릭합니다. 회전/반전 탭에서는 원하는 버튼을 클릭하면 즉시 적용됩니다.

4

미리보기 확인

원본과 결과를 나란히 비교하며 해상도를 확인합니다. 자르기와 회전/반전은 누적으로 적용되므로 두 탭을 오가며 여러 번 편집할 수 있습니다.

5

이미지 다운로드

PNG 다운로드 버튼을 클릭하면 편집된 이미지가 cropimage_result.png 파일로 저장됩니다.

✂️ 자르기 상세 안내

이미지 위에서 드래그하면 선택 영역이 점선 테두리와 코너 핸들로 표시됩니다. 비율 버튼을 먼저 선택하면 드래그 중 가로세로 비율이 고정됩니다.

비율 버튼설명
자유가로세로 비율 제한 없이 원하는 크기로 자유롭게 선택
1:1정방형 — SNS 프로필 사진 등에 적합
4:3일반적인 사진 비율
3:4증명사진 비율
16:9와이드 화면 비율
9:16세로형 — 스토리, 쇼츠 등에 적합

🔄 회전 / 반전 상세 안내

회전과 반전은 클릭 즉시 적용되며, 여러 번 눌러 누적으로 조정할 수 있습니다.

버튼효과
90° 시계 방향이미지를 시계 방향으로 90° 회전 (가로 ↔ 세로 전환)
90° 반시계 방향이미지를 반시계 방향으로 90° 회전 (가로 ↔ 세로 전환)
좌우 반전이미지를 좌우로 뒤집는 거울 효과
상하 반전이미지를 상하로 뒤집기
💡 자르기와 회전/반전은 하나의 작업 캔버스에 누적으로 적용됩니다. 예를 들어 회전한 뒤 자르거나, 자른 뒤 다시 회전하는 것도 가능합니다. 다운로드는 PNG 형식만 지원하므로 다른 형식이 필요하면 FitImage로 추가 변환하세요.

증명사진 비율로 자르거나, 가로·세로 사진을 바로 회전하세요.
서버 전송 없이 브라우저에서 안전하게 처리됩니다.
