줄 번호 추가 사용법 완전 가이드

2026년 7월 9일

LineNumber는 텍스트나 코드에 줄 번호를 붙여 복사하는 무료 온라인 도구입니다. 시작 번호, 구분자, 자릿수 맞춤(0 채우기)까지 원하는 형식으로 자유롭게 설정할 수 있습니다. 모든 처리가 브라우저 내에서만 이루어지므로 입력한 텍스트가 외부 서버로 전송되지 않습니다.

주요 기능

🔢
시작 번호 설정
1이 아닌 다른 숫자부터 시작하고 싶을 때 시작 번호를 직접 지정할 수 있습니다.
✏️
구분자 커스텀
1. , 1: , 1) , 탭 문자 중 선택하거나 원하는 구분자를 직접 입력할 수 있습니다.
🔢
자릿수 맞춤 (0 채우기)
번호 자릿수를 맞춰 001, 002처럼 앞자리를 0으로 채울 수 있습니다.
✅
빈 줄 처리 선택
빈 줄에도 번호를 붙일지, 건너뛰고 다음 줄부터 이어서 번호를 매길지 선택할 수 있습니다.

사용법

1

텍스트 입력

왼쪽 입력창에 줄 번호를 붙이고 싶은 텍스트나 코드를 입력하거나 붙여넣습니다. 입력하는 즉시 오른쪽 결과창에 줄 번호가 붙은 텍스트가 실시간으로 표시됩니다.

2

시작 번호 및 자릿수 설정

시작 번호에 원하는 첫 번호를 입력합니다. 자릿수 맞춤에 값을 입력하면 그 자릿수만큼 앞자리가 0으로 채워집니다 (예: 자릿수 3 → 001).

3

구분자 선택

제공되는 구분자 버튼(. / : / ) / 탭) 중 하나를 클릭하거나, 오른쪽 입력창에 원하는 구분자를 직접 입력합니다.

4

빈 줄에도 번호 붙이기 여부 선택

체크박스를 켜두면(기본값) 빈 줄도 번호가 매겨집니다. 끄면 빈 줄은 번호 없이 그대로 유지되고, 다음 내용 있는 줄부터 번호가 이어서 붙습니다.

5

결과 복사 또는 다운로드

📋 결과 복사 버튼으로 클립보드에 복사하거나, ⬇ .txt 다운로드 버튼으로 파일로 저장합니다.

결과 예시

다음 텍스트에 시작 번호 1, 구분자 . 를 적용한 결과입니다.

apple banana cherry
1. apple 2. banana 3. cherry

구분자별 활용 예시

구분자결과 형태주로 쓰는 곳
. 1. 내용번호 목록, 문서 항목 정리
: 1: 내용로그 파일, 줄 참조용 표시
) 1) 내용설문지, 체크리스트
탭1[Tab]내용스프레드시트에 붙여넣을 표 데이터

활용 예시

🐛
코드 리뷰·질문 시 줄 참조
코드 스니펫에 줄 번호를 붙여 "3번째 줄에 오류가 있어요"처럼 명확하게 소통합니다.
📋
로그 파일 분석
긴 로그 텍스트에 번호를 매겨 특정 줄을 빠르게 짚어 설명하거나 공유합니다.
📝
번호 목록 문서 작성
여러 항목을 붙여넣고 순서대로 번호가 매겨진 목록을 빠르게 만듭니다.
📊
스프레드시트용 데이터 준비
탭 구분자를 사용해 번호와 내용을 각각 다른 셀에 붙여넣을 수 있는 형태로 만듭니다.
🔒 LineNumber는 모든 처리가 브라우저 내에서만 이루어집니다. 입력한 텍스트가 외부 서버로 전송되지 않으므로, 사내 코드나 로그처럼 민감한 내용도 안전하게 처리할 수 있습니다.

텍스트나 코드에 줄 번호를 붙여보세요.
시작 번호와 구분자를 자유롭게 설정할 수 있습니다.
