연봉 실수령액 계산기 사용법 완전 가이드

2026년 7월 12일

연봉 4,000만원이면 월급이 333만원일 것 같지만, 실제 통장에 찍히는 돈은 그보다 30만원 가까이 적습니다. 4대보험과 소득세가 빠져나가기 때문인데, 정확히 얼마가 빠지는지는 급여명세서를 받아보기 전엔 알기 어렵습니다. SalaryCalc는 세전 연봉만 입력하면 국민연금·건강보험·장기요양보험·고용보험과 소득세·지방소득세를 공제한 월 실수령액을 즉시 계산합니다. 아래에서 연봉 4,000만원 기준 실제 계산 결과로 바로 확인해보세요.

주요 기능

💰
즉시 실수령액 계산
연봉만 입력해도 기본값으로 바로 계산되며, 부양가족·비과세액을 조정해 더 정확하게 맞출 수 있습니다.
📋
공제 내역 상세 표시
국민연금, 건강보험, 장기요양보험, 고용보험, 소득세, 지방소득세를 항목별로 확인합니다.
📊
실수령액 비율 그래프
세전 급여 대비 실수령액과 공제액의 비율을 막대 그래프로 시각화합니다.
🔒
완전 로컬 처리
입력한 연봉 정보가 브라우저 안에서만 계산되고 서버로 전송되지 않습니다.

사용법

1

연봉 입력

연봉 (세전, 만원) 칸에 세전 연봉을 만원 단위로 입력합니다. 예를 들어 4,000만원이면 4000을 입력합니다.

2

비과세액·부양가족 정보 입력

식대 등 월 비과세액(기본값 20만원), 본인을 포함한 부양가족 수, 8~20세 자녀 수(자녀세액공제 대상)를 입력합니다. 값이 정확할수록 실제 실수령액에 더 가깝게 계산됩니다.

3

실수령액 계산

💰 실수령액 계산 버튼을 누르면 상단에 예상 월 실수령액과 연 실수령액이 크게 표시됩니다.

4

공제 내역 확인

아래 공제 내역표에서 국민연금·건강보험·장기요양보험·고용보험·소득세·지방소득세 각 항목의 월 공제액과 실수령액 비율 그래프를 확인합니다.

⚠️ 참고: 이 계산기는 2026년 7월 기준 4대보험 요율·소득 상하한액과, 소득세법 시행령 [별표 2] 근로소득 간이세액표(2026.2.27. 개정) 원문 표(월급여 77만~1억원, 부양가족 1~11명)를 그대로 반영해 국세청 공식 계산기와 동일한 소득세·지방소득세 결과를 제공합니다. 총급여 1억원 초과, 부양가족 12명 이상 구간은 표에 첨부된 공식 확장 산식으로 계산합니다. 국민연금 요율은 1998년 이후 28년 만에 인상되어 2026년 4.75%가 적용되며, 이후 매년 0.5%p씩 올라 2033년 13.0%까지 오를 예정입니다. 다만 회사마다 비과세 항목과 공제 구성이 달라 실제 급여명세서와는 차이가 있을 수 있으니 참고용으로 사용하세요.
💡 실제 계산 예시: 연봉 4,000만원(월 비과세 20만원 기본값 적용)이면 → 과세 대상 월급여 약 313만원 기준 국민연금 약 14.9만원 + 건강보험 약 11.3만원 + 장기요양보험 약 1.5만원 + 고용보험 약 2.8만원, 4대보험만 합쳐도 월 약 30만원이 빠집니다. 여기에 소득세·지방소득세까지 더해지면 세전 333만원과 실수령액의 차이가 눈으로 확인됩니다.

계산에 반영되는 항목

항목요율/방식
국민연금과세 대상 급여의 4.75% (2026년 인상분 반영)
건강보험과세 대상 급여의 3.595%
장기요양보험건강보험료의 13.14%
고용보험과세 대상 급여의 0.9%
소득 상하한액국민연금 월 41만~659만원, 건강보험 월 28만~1억 2,772만원 (2026년 7월 기준)
자녀세액공제8~20세 자녀 1명 20,830원, 2명 45,830원, 3명 이상 45,830원+2명 초과 1명당 33,330원 (월, 산출세액에서 직접 차감)
소득세근로소득 간이세액표 원문(월급여·부양가족수별) 조회 — 국세청 공식 계산기와 동일 결과
지방소득세소득세의 10%

💼
이직·연봉협상 준비

💵
월 예산 계획
예상 실수령액을 기준으로 저축·지출 계획을 세웁니다.
🎓

부양가족 수나 자녀 수를 바꿔가며 공제 차이를 비교합니다.

자주 묻는 질문

Q. 연봉 실수령액 계산기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 계산 결과가 실제 급여와 다를 수 있나요?

4대보험 요율과 소득세 기준으로 계산한 참고용 수치입니다. 회사별 수당·공제 항목에 따라 실제 금액과 차이가 있을 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
