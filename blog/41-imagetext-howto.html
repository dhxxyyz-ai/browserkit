이미지 텍스트 추가 사용법 완전 가이드

2026년 7월 9일

ImageText는 이미지 위에 원하는 텍스트를 여러 개 자유롭게 배치할 수 있는 무료 온라인 도구입니다. 캔버스에서 텍스트를 직접 클릭하고 드래그해 위치를 조절할 수 있어, 정해진 9방향 위치에만 넣을 수 있는 일반적인 워터마크 도구보다 자유도가 높습니다. 모든 처리가 브라우저 내에서만 이루어지므로 업로드한 이미지가 외부 서버로 전송되지 않습니다.

주요 기능

🖨️
다중 텍스트 레이어
＋ 텍스트 추가 버튼으로 여러 개의 텍스트 레이어를 만들고, 목록에서 각각 선택해 개별적으로 편집할 수 있습니다.
🖱️
드래그로 위치 조절
캔버스 위에서 텍스트를 클릭한 채로 드래그하면 원하는 위치로 자유롭게 옮길 수 있습니다.
🔠
폰트·크기·색상 설정
4가지 폰트, 크기, 색상, 투명도, 굵게 여부를 텍스트 레이어별로 각각 다르게 지정할 수 있습니다.
🖼️
PNG / JPG / WEBP 저장
완성된 이미지를 원하는 형식으로 다운로드합니다. JPG/WEBP는 투명 배경이 흰색으로 자동 변환됩니다.

사용법

1

이미지 업로드

업로드 존을 클릭하거나 이미지를 드래그해 불러옵니다. JPG, PNG, WEBP 형식을 지원합니다. 업로드하면 기본 텍스트 레이어 1개가 이미지 중앙에 자동으로 생성됩니다.

2

텍스트 추가 및 선택

＋ 텍스트 추가 버튼을 클릭하면 새 텍스트 레이어가 생깁니다. 왼쪽 텍스트 레이어 목록에서 항목을 클릭하면 해당 텍스트가 선택되고, 캔버스에는 보라색 점선 테두리로 표시됩니다.

3

내용 및 스타일 편집

오른쪽 편집 패널에서 텍스트 내용, 폰트, 크기, 투명도, 색상, 굵게 여부를 조절합니다. 값을 바꾸는 즉시 캔버스에 실시간으로 반영됩니다.

4

드래그로 위치 이동

캔버스에서 텍스트를 마우스(또는 손가락)로 누른 채 원하는 위치로 끌어다 놓습니다. 클릭한 지점이 어떤 텍스트에도 해당하지 않으면 드래그가 시작되지 않습니다.

5

불필요한 텍스트 삭제

텍스트 레이어 목록의 ✕ 버튼을 클릭하면 해당 레이어가 삭제됩니다.

6

출력 형식 선택 및 다운로드

PNG / JPG / WEBP 중 원하는 형식을 선택한 뒤 ⬇ 이미지 다운로드 버튼을 클릭합니다. 다운로드된 이미지에는 편집 중 보이던 점선 선택 테두리가 표시되지 않습니다.

WatermarkImage와 무엇이 다른가요?

BrowserKit에는 이미지에 문구를 넣는 도구가 두 가지 있습니다. 용도에 맞게 선택하세요.

구분ImageTextWatermarkImage
목적 이미지 안에 자유롭게 문구/설명 텍스트 삽입 저작권 표시용 워터마크 삽입
텍스트 개수 여러 개 동시 배치 가능 1개 (필요 시 타일 반복)
위치 지정 방식 캔버스에서 자유 드래그 9방향 프리셋 버튼
반복 배치 지원하지 않음 타일 반복 배치 지원

활용 예시

📸
SNS 카드뉴스 제작
배경 이미지 위에 제목, 부제목, 출처 등 여러 텍스트를 각각 원하는 위치에 배치해 카드뉴스를 만듭니다.
🏷️
상품 사진 라벨링
중고거래·쇼핑몰 상품 사진에 가격, 사이즈, 연락처 등의 정보를 이미지에 직접 적어 넣습니다.
📅
밈·짤 제작
사진 위·아래에 자막 형태의 문구를 넣어 재미있는 이미지를 빠르게 만듭니다.
🗺️
여행 사진 설명 추가
여행 사진에 장소명, 날짜 등의 캡션을 여러 위치에 넣어 기록용 이미지를 만듭니다.
🔒 ImageText는 모든 처리가 브라우저 내에서만 이루어집니다. 업로드한 이미지가 외부 서버로 전송되지 않으므로, 아직 공개하지 않은 이미지도 안전하게 편집할 수 있습니다.

자주 묻는 질문

Q. 이미지 텍스트 추가 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 글꼴이나 색상을 바꿀 수 있나요?

네, 텍스트의 크기, 색상, 위치를 조절해 원하는 스타일로 이미지에 합성할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

이미지 위에 원하는 텍스트를 자유롭게 배치해보세요.
드래그 한 번으로 위치를 조절하고 바로 다운로드할 수 있습니다.
