CSS 단위 변환기 사용법 완전 가이드

2026년 7월 9일

CSSUnit은 px, rem, em, vw, vh, % 단위를 기준 폰트 크기와 뷰포트 크기에 맞춰 실시간으로 변환하는 무료 온라인 CSS 단위 변환기입니다. 값을 입력하면 6개 단위로 환산한 결과를 한 번에 확인할 수 있습니다. 모든 계산이 브라우저 내에서만 이루어지므로 입력한 값이 외부 서버로 전송되지 않습니다.

주요 기능

🔢
6종 단위 동시 변환
px, rem, em, vw, vh, %를 한 번에 계산해 표로 보여줍니다. 값을 바꾸면 즉시 재계산됩니다.
⚙️
기준값 커스텀
기준 폰트 크기, 부모 폰트 크기, 뷰포트 너비/높이를 직접 입력해 실제 프로젝트 환경에 맞춘 변환 결과를 얻습니다.
🔄
양방향 변환
어느 단위로 입력해도 나머지 5개 단위로 자동 환산됩니다. px에서 rem으로, rem에서 vw로 자유롭게 전환합니다.
🔒
완전 로컬 처리
모든 계산이 브라우저 안에서 실행됩니다. 값이 서버로 전송되지 않습니다.

사용법

1

기준값 설정

상단 기준값 설정 카드에서 기준 폰트 크기(rem 기준), 부모 폰트 크기(em/% 기준), 뷰포트 너비/높이(vw/vh 기준)를 실제 사용 중인 CSS 환경에 맞게 입력합니다. 기본값은 각각 16px, 16px, 1920px, 1080px입니다.

2

값과 단위 입력

변환할 값을 입력하고, 드롭다운에서 그 값의 단위(px/rem/em/vw/vh/%)를 선택합니다.

3

결과 확인 및 복사

아래 표에 6개 단위로 환산된 결과가 모두 표시됩니다. 입력한 단위 행은 강조 표시됩니다. 각 행의 복사 버튼으로 값+단위를 바로 클립보드에 복사할 수 있습니다.

단위별 계산 방식

단위기준px 환산 공식
rem기준 폰트 크기(root)값 × 기준 폰트 크기
em부모 폰트 크기값 × 부모 폰트 크기
vw뷰포트 너비값 × 뷰포트 너비 ÷ 100
vh뷰포트 높이값 × 뷰포트 높이 ÷ 100
%부모 폰트 크기값 × 부모 폰트 크기 ÷ 100
⚠️ 주의: em과 %는 실제 CSS에서 요소마다 부모의 폰트 크기가 다를 수 있어 계산 결과가 달라집니다. CSSUnit은 입력한 "부모 폰트 크기" 기준값 하나로 통일해 계산하므로, 중첩된 요소에서 em이 누적 적용되는 경우(부모의 부모까지 영향을 주는 경우)는 반영하지 않습니다. 정확한 값이 필요하다면 실제 DOM 구조를 기준으로 직접 확인하세요.

활용 예시

📐
반응형 디자인 값 환산
디자인 시안의 px 값을 rem이나 vw로 빠르게 환산해 반응형 CSS에 바로 적용합니다.
📖
타이포그래피 스케일 확인
기준 폰트 크기를 바꿔가며 rem 기반 폰트 크기 체계가 px로 얼마인지 미리 확인합니다.
🖥️
뷰포트 단위 계산
특정 해상도에서 vw/vh 값이 실제 몇 px인지 계산해 히어로 섹션이나 풀스크린 레이아웃을 설계합니다.
🎓
CSS 단위 학습
rem, em, vw, vh, % 단위가 서로 어떻게 관계되는지 실제 숫자로 비교하며 학습합니다.
🔒 CSSUnit은 모든 계산이 내 PC 브라우저에서만 실행됩니다. 입력한 값이 외부 서버로 전송되지 않습니다.

자주 묻는 질문

Q. CSS 단위 변환기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 어떤 단위를 변환할 수 있나요?

px, rem, em 등 CSS에서 자주 쓰는 단위를 기준 폰트 크기에 맞춰 상호 변환합니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

px, rem, em, vw, vh, % 단위를 기준값에 맞춰 실시간으로 변환해보세요.
값을 입력하면 6개 단위가 한 번에 표시됩니다.
