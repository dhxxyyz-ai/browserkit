텍스트 마스킹 사용법 완전 가이드

2026년 6월 18일 (2026년 7월 3일 수정)

MaskDoc은 복사한 텍스트 속 주민번호, 전화번호, 이메일, 계좌번호를 자동으로 탐지해 마스킹하는 무료 도구입니다. 이미지 기반 도구와 달리 OCR 없이 텍스트를 그대로 붙여넣으면 즉시 처리되며, 모든 작업이 브라우저 내에서만 이루어져 텍스트가 외부 서버로 전송되지 않습니다.

주요 기능

🆔
주민등록번호 마스킹
전체 가리기, 뒷자리 전체, 뒷자리 6자리 3가지 방식을 선택할 수 있습니다.
📱
전화번호 마스킹
전체 가리기, 뒤 8자리, 뒤 4자리 3가지 방식을 지원합니다.
📧
이메일 마스킹
전체 가리기 또는 아이디만 가리기를 선택할 수 있습니다.
🏦
계좌번호 마스킹
전체 가리기 또는 뒤 4자리만 가리기를 지원합니다.

기본 사용법

1

탐지 항목 ON/OFF 설정

화면 상단의 4개 카드에서 마스킹할 항목을 선택합니다. 각 카드 오른쪽 토글로 항목별 활성/비활성을 설정하고, 라디오 버튼으로 마스킹 방식을 선택합니다.

2

텍스트 붙여넣기

왼쪽 입력 영역에 마스킹할 텍스트를 붙여넣거나 직접 입력합니다. 입력과 동시에 탐지 결과 요약이 실시간으로 표시됩니다.

3

마스킹 적용

🛡️ 마스킹 적용 버튼을 클릭하면 오른쪽 결과 영역에 마스킹된 텍스트가 표시됩니다.

4

복사 또는 다운로드

📋 결과 복사로 클립보드에 복사하거나, ⬇ .txt 다운로드로 maskdoc_result.txt 파일로 저장합니다.

MaskDoc vs MaskPrivacy 비교

MaskDoc과 MaskPrivacy는 목적이 다른 도구입니다. 상황에 맞게 선택하세요.

항목MaskDocMaskPrivacy
처리 대상텍스트 (복사/붙여넣기)이미지 (JPG, PNG 등)
탐지 방식정규식 (즉시)OCR (시간 소요)
처리 속도즉시수 초~수십 초
정확도높음 (텍스트 기반)OCR 정확도에 의존
출력 형식텍스트 (.txt)이미지 (.png)
추천 상황문서, 이메일, 메모장 텍스트스캔 문서, 캡처 이미지
💡 MaskDoc은 텍스트를 그대로 붙여넣으면 즉시 처리되므로 속도가 매우 빠릅니다. 정규식 기반 탐지이므로 OCR 오탐 없이 높은 정확도를 유지합니다. 단, 이미지나 PDF에서 개인정보를 제거하려면 MaskPrivacy 또는 MaskPDF를 사용하세요.

텍스트를 붙여넣으면 주민번호·전화번호·이메일을 즉시 마스킹합니다.
OCR 없이 순수 텍스트를 처리하므로 오탐이 없습니다.
