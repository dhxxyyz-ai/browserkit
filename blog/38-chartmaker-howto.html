차트 생성기 사용법 완전 가이드

2026년 6월 24일

발표 자료에 넣을 차트 하나 만들려고 엑셀을 켜고, 스타일을 맞추고, 이미지로 내보내는 과정이 생각보다 번거롭습니다. ChartMaker는 데이터를 입력하거나 CSV 파일을 업로드해 막대·선형·원형·도넛·레이더·폴라 차트를 즉시 만들 수 있는 무료 온라인 도구입니다. 완성된 차트는 PNG나 SVG로 바로 저장할 수 있고, 모든 처리가 브라우저 안에서만 이루어지므로 데이터가 외부 서버로 전송되지 않습니다.

주요 기능

📊
차트 6종 지원
막대, 선형, 원형, 도넛, 레이더, 폴라 차트를 상단 버튼으로 즉시 전환해 생성할 수 있습니다.
📂
CSV 파일 업로드
스프레드시트에서 내보낸 CSV를 드래그&드롭으로 업로드하면 자동으로 데이터를 불러와 차트를 생성합니다.
🖼️
PNG / SVG 저장
완성된 차트를 PNG(배경 포함) 또는 SVG 파일로 저장합니다. 배경을 흰색, 투명, 다크로 선택할 수 있습니다.
⚙️
다양한 옵션
범례, 데이터 레이블, 격자선, 배경색, 누적 차트 옵션을 토글로 자유롭게 설정할 수 있습니다.

화면 구성

상단의 차트 타입 버튼에서 원하는 종류를 선택한 뒤, 좌측 설정 패널에서 데이터와 옵션을 입력하고 우측에서 차트를 확인합니다.

기본 사용법

1

차트 타입 선택

상단 버튼에서 원하는 차트 종류를 선택합니다. 기본값은 막대 차트이며, 타입을 바꿔도 입력한 데이터는 유지됩니다.

📊 막대
📈 선형
⭕ 원형
🍩 도넛
🕸️ 레이더
🎯 폴라
2

데이터 입력

데이터 입력 테이블에서 색상 피커로 각 항목 색상을 지정하고, 레이블과 값을 입력합니다. 기본으로 1~6월 샘플 데이터 6개가 입력되어 있으며, + 행 추가 버튼으로 항목을 늘릴 수 있습니다.

3

차트 제목 입력 (선택)

차트 제목 입력창에 원하는 제목을 입력합니다. 제목은 차트 상단에 표시되며 PNG 저장 시 파일명으로도 사용됩니다.

4

옵션 설정 (선택)

범례, 데이터 레이블, 격자선, 배경색 등을 설정합니다. 막대와 선형 차트에서는 X축·Y축 레이블을, 막대 차트에서는 누적 차트 옵션도 추가로 사용할 수 있습니다.

5

차트 생성

📊 차트 생성 버튼을 클릭하면 오른쪽 패널에 차트가 렌더링됩니다.

6

저장

PNG 저장으로 이미지를 다운로드하거나, SVG 저장으로 벡터 파일을 저장합니다.

📊 차트 생성
🖼️ PNG 저장
📄 SVG 저장
↺ 초기화

CSV 파일 업로드

엑셀이나 구글 스프레드시트에서 데이터를 CSV로 내보낸 뒤 업로드하면 자동으로 차트를 생성합니다. 첫 번째 열이 레이블, 두 번째 열이 값으로 인식됩니다.

CSV 파일 형식 예시

카테고리,판매량
1월,120
2월,190
3월,170
4월,250
5월,310
6월,280

첫 번째 행이 헤더(숫자가 아닌 텍스트)이면 자동으로 건너뜁니다. 드래그&드롭 또는 클릭으로 파일을 업로드하면 즉시 데이터가 불러와지고 차트가 자동 생성됩니다.

차트 타입별 특징

타입아이콘적합한 데이터특징
막대📊항목 간 수치 비교누적 차트 옵션 지원. 가장 범용적인 차트.
선형📈시간에 따른 변화 추이월별 매출, 주가 흐름 등 추세 표현에 적합.
원형⭕전체 대비 비율항목별 구성 비율을 직관적으로 표현.
도넛🍩전체 대비 비율원형과 동일하나 중앙이 비어 있어 더 세련된 느낌.
레이더🕸️다항목 능력치 비교스킬, 역량, 평가 항목 시각화에 적합.
폴라🎯방향별 수치 비교레이더와 유사하나 조각 면적으로 크기를 표현.

차트 옵션 설명

📖 범례 표시
🏷️ 데이터 레이블
▦ 격자선
🎨 배경색흰색
📊 누적 차트 (막대 전용)
옵션설명
범례 표시차트 아래에 항목명과 색상 범례를 표시합니다.
데이터 레이블각 데이터 포인트에 수치를 직접 표시합니다. 원형/도넛은 조각 내부, 막대/선형은 위에 표시됩니다.
격자선막대/선형 차트의 배경 격자선을 켜거나 끕니다.
배경색투명(PNG 저장 시 배경 없음) / 흰색 / 다크 중 선택합니다.
누적 차트막대 차트 전용. 각 항목의 값이 왼쪽부터 오른쪽으로 누계로 쌓이면서 표시됩니다. 예) 1월=120, 2월=310, 3월=480...

활용 예시

💰
월별 매출 리포트
월별 매출 데이터를 막대 또는 선형 차트로 시각화해 보고서나 발표 자료에 삽입합니다.
🥧
예산 구성 비율
항목별 예산 배분을 원형 또는 도넛 차트로 표현해 전체 대비 비율을 한눈에 파악합니다.
🧑‍💼
역량 평가 시각화
직원 역량 평가 항목을 레이더 차트로 시각화해 강점과 약점을 직관적으로 표현합니다.
📈
주간 방문자 추이
웹사이트 주간 방문자 수를 선형 차트로 시각화해 트래픽 변화 패턴을 분석합니다.
🎓
발표 자료용 차트
파워포인트나 Keynote 발표 자료에 삽입할 차트를 PNG로 저장해 바로 활용합니다.
📝
설문 결과 시각화
설문 응답 데이터를 CSV로 내보낸 뒤 업로드해 즉시 원형 차트로 시각화합니다.

PNG vs SVG 저장 차이

형식특징추천 사용 상황
PNG배경 포함 이미지 파일. 설정한 배경색(투명/흰색/다크)이 적용됩니다.발표 자료, 보고서, SNS 공유, 문서 삽입
SVG벡터 기반 파일. 어떤 크기로 확대해도 선명하게 유지됩니다.웹사이트 삽입, 인쇄용 고해상도 출력
🔒 ChartMaker는 모든 데이터 처리가 브라우저 안에서만 실행됩니다. 입력한 데이터와 CSV 파일이 외부 서버로 전송되지 않으므로 매출, 인사 등 민감한 업무 데이터도 안심하고 사용할 수 있습니다.

자주 묻는 질문

Q. 차트 생성기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 만든 차트는 어떻게 저장하나요?

완성된 차트를 이미지 파일로 다운로드해 문서나 발표 자료에 바로 활용할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
