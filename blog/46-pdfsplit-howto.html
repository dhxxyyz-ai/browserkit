PDF 분할 사용법 완전 가이드

2026년 7월 9일

PDFSplit은 하나의 PDF 파일을 페이지별로 분할하거나, 원하는 범위만 골라 추출하는 무료 온라인 도구입니다. PDFMerge와 동일한 PDF.js·jsPDF 엔진을 사용하며, 여러 페이지를 개별 파일로 나눌 때는 ZIP으로 한 번에 다운로드할 수 있습니다. 모든 처리가 브라우저 내에서만 이루어지므로 업로드한 PDF가 외부 서버로 전송되지 않습니다.

주요 기능

📄
페이지별 분할
모든 페이지를 개별 PDF 파일로 만들어 ZIP 하나로 묶어 다운로드합니다. 원하는 페이지만 선택해서 분할할 수도 있습니다.
✂️
범위 지정 분할
"1-3, 5"처럼 원하는 페이지 범위만 입력하면 그 페이지들만 모아 하나의 PDF로 추출합니다.
🖼️
페이지 미리보기
업로드하면 모든 페이지의 썸네일이 그리드로 표시되어, 몇 번째 페이지인지 직접 보면서 선택할 수 있습니다.
🔒
완전 로컬 처리
PDF 렌더링부터 분할, 압축까지 전부 브라우저 안에서 처리되어 파일이 서버로 전송되지 않습니다.

사용법

1

PDF 업로드

업로드 존을 클릭하거나 PDF 파일을 드래그해 불러옵니다. 파일 하나만 업로드할 수 있습니다. 업로드하면 모든 페이지의 썸네일이 자동으로 생성됩니다.

2

분할 방식 선택

상단 탭에서 원하는 방식을 선택합니다.

📄 페이지별 분할 ✂️ 범위 지정 분할

페이지별 분할

3

분할할 페이지 선택

기본적으로 모든 페이지가 선택되어 있습니다. 썸네일을 클릭하면 선택/해제되고, 전체 선택 / 선택 해제 버튼으로 한 번에 조정할 수도 있습니다. 선택된 페이지 각각이 개별 PDF 파일이 됩니다.

범위 지정 분할

3

페이지 범위 입력

입력창에 원하는 페이지 범위를 입력합니다 (예: 1-3, 5). 비워두면 전체 페이지가 하나의 PDF로 추출됩니다.

4

분할하고 다운로드

⬇ 분할하고 다운로드 버튼을 클릭합니다. 페이지별 분할 모드에서는 pdfsplit_pages.zip 파일이, 범위 지정 분할 모드에서는 pdfsplit_range.pdf 파일이 다운로드됩니다.

페이지별 분할 vs 범위 지정 분할, 언제 쓰나요?

방식결과물추천 상황
페이지별 분할 선택한 페이지 수만큼의 개별 PDF (ZIP 1개) 각 페이지를 완전히 독립된 파일로 나눠 각각 전달·보관하고 싶을 때
범위 지정 분할 지정한 페이지들만 모은 PDF 1개 전체 문서 중 필요한 부분만 발췌해 하나의 파일로 공유하고 싶을 때

활용 예시

📑
계약서 조항별 분리
긴 계약서에서 특정 조항이 담긴 페이지만 골라 별도 PDF로 공유합니다.
📚
스캔 문서 페이지 분리
여러 문서를 한 번에 스캔해 만든 PDF를 페이지별로 분할해 각 문서로 되돌립니다.
📊
보고서 요약본 추출
전체 보고서에서 요약·결론 페이지만 추출해 짧은 버전으로 공유합니다.
📤
용량 제한 우회
첨부 용량 제한이 있는 경우, 필요한 페이지만 추출해 파일 크기를 줄여 전송합니다.
🔒 PDFSplit은 모든 처리가 브라우저 내에서만 이루어집니다. 업로드한 PDF가 외부 서버로 전송되지 않으므로, 계약서·보고서 등 민감한 문서도 안전하게 분할할 수 있습니다.

자주 묻는 질문

Q. PDF 분할 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

Q. 업로드한 파일이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 업로드한 파일이 외부 서버로 전송되거나 저장되지 않습니다.

Q. 특정 페이지만 골라서 추출할 수 있나요?

네, 페이지 범위를 지정해 필요한 부분만 별도의 PDF로 저장할 수 있습니다.

Q. 모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.

PDF를 페이지별로 분할하거나 원하는 범위만 추출해보세요.
ZIP 또는 PDF 파일로 바로 다운로드할 수 있습니다.
