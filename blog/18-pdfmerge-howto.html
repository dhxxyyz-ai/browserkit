PDFMerge 사용법 완전 가이드

2026년 6월 16일

PDFMerge는 여러 PDF를 하나로 합치거나 특정 페이지만 추출하는 무료 온라인 도구입니다. 설치 없이 바로 사용할 수 있으며, 모든 처리가 브라우저 내에서만 이루어져 PDF 파일이 외부 서버로 전송되지 않습니다.

주요 기능

📄
다중 PDF 업로드
여러 PDF 파일을 한 번에 업로드합니다. 드래그앤드롭과 파일 선택 모두 지원합니다.
🖼️
썸네일 미리보기
각 파일의 첫 페이지를 썸네일로 렌더링해 파일을 시각적으로 확인할 수 있습니다.
↕️
드래그로 순서 변경
파일 카드를 드래그해 합쳐질 순서를 자유롭게 조정합니다.
📑
페이지 범위 선택
파일별로 포함할 페이지를 지정할 수 있습니다. (예: 1-3, 5) 비워두면 전체 페이지가 포함됩니다.
➕
파일 추가 / 삭제
업로드 후에도 파일을 추가하거나 개별 삭제할 수 있습니다.
📥
PDF 다운로드
처리 완료된 파일을 즉시 pdfmerge_result.pdf로 다운로드합니다.

기본 사용법

1

PDF 파일 업로드

업로드 영역에 PDF 파일을 드래그하거나 클릭해서 파일을 선택합니다. 여러 파일을 동시에 선택할 수 있습니다.

2

파일 목록 확인

업로드된 파일이 카드 형태로 표시됩니다. 각 카드에는 파일명, 페이지 수, 파일 크기, 첫 페이지 썸네일이 표시됩니다. + 파일 추가 버튼으로 파일을 더 추가할 수 있습니다.

3

순서 조정 및 페이지 범위 입력

카드를 드래그해 합쳐질 순서를 조정합니다. 특정 페이지만 포함하려면 페이지 범위 입력 필드에 범위를 입력합니다. (예: 1-3, 5 → 1, 2, 3, 5페이지만 포함)

4

PDF 합치기 및 다운로드

PDF 합치기 및 다운로드 버튼을 클릭합니다. 페이지 수에 따라 처리 시간이 달라지며 진행 상황이 Progress Bar로 표시됩니다. 완료되면 pdfmerge_result.pdf가 자동으로 다운로드됩니다.

5

처음부터 다시

처음부터 버튼으로 초기화하고 새로운 작업을 시작할 수 있습니다.

페이지 범위 입력 방법

페이지 범위 필드를 비워두면 해당 파일의 전체 페이지가 포함됩니다. 아래와 같이 다양한 방식으로 입력할 수 있습니다.

입력 예시결과
비워둠전체 페이지 포함
1-31, 2, 3페이지
1, 3, 51, 3, 5페이지
1-3, 51, 2, 3, 5페이지
2-4, 7-92, 3, 4, 7, 8, 9페이지
