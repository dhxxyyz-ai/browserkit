FindReplace 사용법 완전 가이드

2026년 6월 23일

FindReplace는 텍스트에서 단어를 찾아 일괄 치환하는 무료 온라인 도구입니다. 메모장이나 엑셀의 찾기/바꾸기처럼 사용할 수 있고, 정규식 모드를 활성화하면 패턴 기반의 고급 치환도 가능합니다. 주민번호·전화번호·이메일 마스킹 프리셋이 내장되어 있어 개인정보 일괄 처리에도 바로 활용할 수 있습니다. 모든 처리가 브라우저 안에서만 이루어지므로 텍스트가 외부 서버로 전송되지 않습니다.

주요 기능

🔄
찾아 바꾸기
텍스트에서 특정 단어를 찾아 다른 단어로 일괄 치환합니다. 전체 치환 또는 첫 번째 항목만 치환하는 옵션을 선택할 수 있습니다.
🔦
매칭 미리보기
치환 실행 전에 매칭 위치를 보라색으로 하이라이트해 미리 확인할 수 있습니다. 실수로 잘못된 곳을 치환하는 사고를 예방합니다.
🧪
정규식 모드
정규식(Regular Expression)으로 패턴 기반 치환을 할 수 있습니다. 캡처 그룹($1 $2)을 이용한 복잡한 치환도 지원합니다.
🛡️
개인정보 마스킹 프리셋
주민번호·전화번호·이메일을 클릭 한 번으로 일괄 마스킹합니다. 정규식을 몰라도 바로 사용할 수 있습니다.

기본 사용법

1

입력 텍스트 붙여넣기

상단 입력 텍스트 영역에 치환할 텍스트를 입력하거나 붙여넣습니다. 우측에 글자 수와 줄 수가 실시간으로 표시됩니다.

2

찾을 내용 입력

왼쪽 패널의 찾을 내용 입력창에 찾고 싶은 텍스트를 입력합니다. 입력하는 즉시 오른쪽 미리보기에 보라색 하이라이트로 매칭 위치가 표시됩니다.

3

바꿀 내용 입력

바꿀 내용 입력창에 치환 후 표시될 텍스트를 입력합니다. 비워두면 찾은 내용이 삭제됩니다.

4

치환 실행

매칭 개수 배지에서 치환 대상 개수를 확인한 뒤 치환 실행 버튼을 클릭합니다. 오른쪽 하단의 치환 결과 영역에 결과가 표시됩니다.

5

결과 복사 또는 저장

결과 복사 버튼으로 클립보드에 복사하거나 .txt 저장 버튼으로 파일을 다운로드합니다. 교체 버튼을 누르면 결과가 입력창으로 이동해 연속 치환이 가능합니다.

매칭 미리보기 예시

아래는 홍길동을 찾을 내용에 입력했을 때 미리보기 영역에 표시되는 모습입니다.

🔦 매칭 미리보기 ✨ 3개 일치
이름: 홍길동 연락처: 010-1234-5678 담당자: 홍길동 과장 서명: 홍길동

옵션 토글 설명

Aa 전체 .* ^$
버튼기능설명
Aa대소문자 구분활성화 시 대소문자를 구분합니다. Hello와 hello를 다른 단어로 취급합니다. 기본값: 비활성(대소문자 무시)
전체전체 치환활성화 시 일치하는 모든 항목을 치환합니다. 비활성화 시 첫 번째 항목만 치환합니다. 기본값: 활성
.*정규식 모드활성화 시 찾을 내용을 정규식으로 해석합니다. 패턴 기반 치환이 필요할 때 사용합니다.
^$여러 줄 모드정규식의 ^(줄 시작), $(줄 끝)이 각 줄에 적용됩니다. 빈 줄 제거 프리셋 등에서 사용합니다.

정규식 모드 사용법

정규식 모드(.*) 버튼을 활성화하면 찾을 내용을 정규식 패턴으로 해석합니다. 활성화 시 입력창 아래에 정규식 빠른 참고 표가 자동으로 펼쳐집니다.

패턴의미예시
.임의의 문자 1개h.t → hat, hit, hot 등 매칭
\d숫자 [0-9]\d\d\d → 세 자리 숫자
\w단어 문자 [a-zA-Z0-9_]
\s공백 문자 (스페이스, 탭)\s+ → 하나 이상의 공백
+앞 패턴 1개 이상\d+ → 1자리 이상 숫자
*앞 패턴 0개 이상
{n,m}앞 패턴 n~m개\d{6} → 정확히 6자리 숫자
(abc)캡처 그룹치환 시 $1로 참조 가능
^줄 시작 (여러 줄 모드 필요)
$줄 끝 (여러 줄 모드 필요)
|또는cat|dog → cat 또는 dog

캡처 그룹 활용 예시

정규식의 캡처 그룹 ()으로 묶은 부분은 바꿀 내용에서 $1, $2로 참조할 수 있습니다. 전화번호 뒷자리 마스킹이 대표적인 예입니다.

찾을 내용 (01[0-9])-(\d{3,4})-(\d{4}) → 바꿀 내용: $1-****-$3
원본 010-1234-5678 → 010-****-5678

첫 번째 그룹 $1(010)과 세 번째 그룹 $3(5678)은 그대로 두고, 가운데 번호만 ****로 치환합니다.

개인정보 마스킹 프리셋

정규식을 직접 작성하지 않아도 프리셋 버튼을 클릭하면 자동으로 찾을 내용과 바꿀 내용이 입력됩니다. 정규식 모드도 자동으로 활성화됩니다.

연속 공백 → 단일 공백 앞뒤 공백 제거 빈 줄 제거 주민번호 마스킹 전화 뒷자리 마스킹 이메일 마스킹
주민번호 901225-1234567 → ******-*******
전화번호 010-1234-5678 → 010-****-5678
이메일 user@example.com → ***@***.***

텍스트 정리 프리셋

프리셋효과활용 상황
연속 공백 → 단일 공백두 칸 이상 공백을 한 칸으로 줄임붙여넣기한 텍스트 정리
앞뒤 공백 제거각 줄의 앞뒤 공백 제거엑셀 데이터 정제
빈 줄 제거빈 줄 전체 삭제문서 압축, 로그 정리

활용 예시

📋
계약서 개인정보 마스킹
계약서 텍스트를 붙여넣고 주민번호·전화번호·이메일 프리셋을 순서대로 클릭해 일괄 마스킹합니다. 교체 버튼으로 연속 치환이 가능합니다.
📊
엑셀 데이터 정제
엑셀에서 복사한 텍스트의 앞뒤 공백 제거, 연속 공백 정리, 빈 줄 제거를 프리셋으로 빠르게 처리합니다.
📝
용어 일괄 변경
문서에서 특정 단어를 다른 단어로 일괄 변경합니다. 예를 들어 "고객사"를 "클라이언트"로, "담당자"를 "매니저"로 전체 교체합니다.
💻
코드 텍스트 치환
변수명이나 함수명을 일괄 변경할 때 정규식 모드로 정확한 패턴 매칭 치환을 할 수 있습니다.
💬
날짜 형식 변환
정규식으로 (\d{4})-(\d{2})-(\d{2}) 패턴을 찾아 $3/$2/$1로 치환해 날짜 형식(YYYY-MM-DD → DD/MM/YYYY)을 변환합니다.
🗑️
로그 파일 정리
로그 텍스트에서 빈 줄 제거, 특정 오류 패턴 치환, 타임스탬프 형식 변경 등을 정규식으로 처리합니다.

연속 치환 팁

한 번의 치환 결과에 다시 치환을 적용해야 할 때는 교체(↕) 버튼을 활용합니다.

1

첫 번째 치환 실행

주민번호 마스킹 프리셋으로 첫 번째 치환을 완료합니다.

2

교체 버튼 클릭

교체(↕) 버튼을 클릭하면 치환 결과가 입력 텍스트 영역으로 이동합니다.

3

두 번째 치환 실행

이제 전화번호 마스킹 프리셋으로 두 번째 치환을 실행합니다. 이렇게 여러 프리셋을 순서대로 적용할 수 있습니다.

🔄 FindReplace의 모든 처리는 브라우저 안에서만 실행됩니다. 주민번호, 이메일 등 민감한 개인정보가 포함된 텍스트도 외부 서버로 전송되지 않으므로 안심하고 사용할 수 있습니다.

긴 문서에서 특정 단어를 일괄 교체해야 할 때 FindReplace를 사용하세요.
정규식 모드로 복잡한 패턴도 한 번에 처리합니다.
