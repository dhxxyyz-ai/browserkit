사용법 요약

  1. 마크다운 입력
  2. 툴바 버튼 활용 (선택)
  3. 저장 또는 복사

자주 묻는 질문

마크다운 편집기 도구는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 횟수 제한도 없습니다.

입력한 내용이 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용이 외부 서버로 전송되거나 저장되지 않습니다.

작성한 내용이 자동으로 저장되나요?

작성 내용은 브라우저 안에서만 처리되므로, 작업이 끝나면 결과물을 복사하거나 별도로 저장해 두세요.

모바일에서도 사용할 수 있나요?

네, 별도의 앱 설치 없이 모바일 브라우저에서도 동일하게 사용할 수 있습니다.
