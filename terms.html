BrowserKit ← BrowserKit 홈으로

이용약관

시행일: 2026년 6월 10일  |  최종 수정일: 2026년 7월 17일

BrowserKit 서비스를 이용하시기 전에 본 약관을 주의 깊게 읽어 주시기 바랍니다.
서비스를 이용하시면 본 약관에 동의하신 것으로 간주됩니다.

제1조 (목적)

본 약관은 BrowserKit(이하 "서비스")이 제공하는 브라우저 기반 무료 도구 모음의 이용 조건 및 절차, 이용자와 서비스 간의 권리·의무 및 책임 사항을 규정함을 목적으로 합니다.

제2조 (서비스 정의)

BrowserKit은 브라우저에서 바로 사용할 수 있는 무료 온라인 도구 모음입니다. 현재 제공 중인 서비스는 다음과 같습니다.

개인정보

  • 개인정보 마스킹 (MaskPrivacy): 이미지 속 개인정보 자동 탐지 및 마스킹
  • PDF 마스킹 (MaskPDF): PDF 개인정보 자동 탐지 및 마스킹
  • 얼굴 블러 (MaskFace): 이미지 속 얼굴 자동 감지 및 모자이크
  • 텍스트 마스킹 (MaskDoc): 텍스트 속 개인정보 정규식 자동 치환
  • 사진 위치정보 제거기 (ExifRemover): 이미지 EXIF 메타데이터 제거

이미지 편집

  • 이미지 변환 (FitImage): 이미지 크기 조정 / 형식 변환 / 용량 압축
  • 이미지 자르기 (CropImage): 자르기 / 회전 / 반전
  • 워터마크 추가 (WatermarkImage): 텍스트 및 이미지 워터마크 합성
  • 색상 추출 (ColorPicker): 이미지 픽셀 색상 추출 및 팔레트 저장
  • 이미지 보정 (ImageBright): 밝기 / 대비 / 채도 / 색온도 슬라이더 보정
  • AI 배경 제거 (BGRemove): AI 모델로 이미지 배경 자동 제거
  • 이미지 텍스트 추가 (ImageText): 이미지 위에 텍스트 합성
  • 이미지 필터 (ImageFilter): 다양한 이미지 필터 효과 적용
  • 이미지 모아 붙이기 (ImageCollage): 여러 이미지를 하나의 콜라주로 합성
  • 픽셀 아트 변환 (PixelArt): 이미지를 픽셀 아트 스타일로 변환
  • 모자이크 생성기 (MosaicMaker): 이미지 모자이크 효과 적용
  • 즐겨찾기 아이콘 생성기 (FaviconGen): 이미지를 파비콘으로 변환
  • SVG → PNG 변환기 (SVGtoPNG): SVG 파일을 PNG로 변환
  • 이미지 비교 슬라이더 (ImageCompare): 두 이미지를 슬라이더로 비교
  • 이미지 테두리 추가 (ImageFrame): 이미지에 테두리/프레임 합성
  • 디바이스 목업 생성기 (MockupFrame): 이미지를 기기 목업에 합성
  • GIF 애니메이션 생성기 (GifMaker): 여러 이미지를 GIF 애니메이션으로 합성

문서·텍스트

  • PDF 합치기 (PDFMerge): 여러 PDF 합치기 및 페이지 추출
  • PDF 분할 (PDFSplit): PDF 파일을 페이지 단위로 분할
  • 텍스트 변환 (TextTools): 글자수 세기 / 공백 정리 / 대소문자 변환 / 중복 제거
  • 텍스트 비교 (DiffChecker): 두 텍스트 차이점 줄 단위 하이라이트
  • 마크다운 편집기 (MarkdownEditor): 실시간 마크다운 → HTML 미리보기
  • 찾아 바꾸기 (FindReplace): 텍스트 일괄 치환, 정규식 모드 지원
  • 줄 번호 추가 (LineNumber): 텍스트에 줄 번호 자동 삽입
  • 더미 텍스트 생성기 (LoremGen): 로렘입숨 등 더미 텍스트 생성
  • CSV ↔ JSON 변환기 (CSVJSONConvert): CSV와 JSON 상호 변환
  • YAML ↔ JSON 변환기 (YAMLJSONConvert): YAML과 JSON 상호 변환
  • 텍스트 통계 분석기 (TextStats): 글자수/단어수/문장 통계 분석
  • 표 변환기 (MarkdownTableConvert): 표 데이터를 마크다운 표로 변환
  • PDF 비밀번호 해제 (PDFPasswordRemove): PDF 잠금 해제
  • PDF 비밀번호 설정 (PDFPasswordSet): PDF에 비밀번호 및 권한 설정
  • 엑셀 ↔ CSV 변환기 (XlsxCsvConvert): 엑셀·CSV 상호 변환, 다중 시트 지원

유틸리티

  • QR 코드 생성 (QRCode): URL / 텍스트 / 연락처 QR 코드 생성
  • 비밀번호 생성기 (PasswordGen): 안전한 난수 기반 비밀번호 생성
  • 단위 변환기 (UnitConvert): 길이 / 무게 / 온도 / 넓이 / 속도 변환
  • 날짜 계산기 (DateCalc): D-day / 날짜 차이 / 나이 계산
  • 세계 시계 (WorldClock): 실시간 세계 도시 시간 확인 및 시간대 변환
  • 랜덤 추첨기 (RandomPicker): 목록에서 무작위 항목 추첨
  • 집중 · 휴식 타이머 (PomodoroTimer): 뽀모도로 기법 타이머
  • QR 코드 스캐너 (QRScanner): 카메라/이미지로 QR 코드 인식
  • 사다리타기 (LadderGame): 사다리 타기 게임

개발자

  • JSON 포맷터 (JSONFormat): JSON 정렬 / 압축 / 유효성 검사
  • 정규식 테스터 (RegexTest): 정규식 실시간 매칭 하이라이트
  • Base64 변환 (Base64Tool): 텍스트 및 이미지 ↔ Base64 변환
  • 해시 생성기 (HashGen): MD5 / SHA-1 / SHA-256 / SHA-512 해시 생성
  • 코드 압축기 (Minifier): HTML/CSS/JS 코드 압축
  • URL 인코더 (URLEncode): URL 인코딩/디코딩
  • CSS 단위 변환기 (CSSUnit): px/rem/em 등 CSS 단위 변환
  • UUID 생성기 (UUIDGen): UUID 자동 생성
  • JWT 디코더 (JWTDecoder): JWT 토큰 디코딩 및 검증
  • Cron 표현식 도우미 (CronHelper): Cron 표현식 생성 및 해석
  • SQL 포맷터 (SQLFormatter): SQL 쿼리 정렬/포맷팅
  • 색상 코드 변환기 (ColorConverter): HEX/RGB/HSL 등 색상 코드 변환
  • 코드 스니펫 이미지 생성기 (CodeSnapshot): 코드를 이미지로 캡처
  • HTTP 상태 코드 사전 (HttpStatusRef): HTTP 상태 코드 검색·설명 조회

데이터·시각화

  • 차트 생성기 (ChartMaker): 다양한 유형의 차트 생성
  • 다이어그램 생성기 (DiagramMaker): 순서도/다이어그램 작성
  • 색상 팔레트 생성기 (PaletteGen): 색상 팔레트 추출 및 생성
  • 워드클라우드 생성기 (WordCloudGen): 텍스트 기반 워드클라우드 생성

계산기

  • 연봉 실수령액 계산기 (SalaryCalc): 연봉 기준 실수령액 계산
  • 환율 계산기 (CurrencyCalc): 실시간 환율 기준 통화 변환
  • 대출 이자 계산기 (LoanCalc): 대출 원리금 및 이자 계산
  • 적금·예금 만기 계산기 (SavingsCalc): 정기적금·예치식 만기 수령액 단리·복리 계산
  • 부가세 계산기 (VatCalc): 공급가액·합계금액 기준 부가가치세 양방향 계산
  • 퇴직금 계산기 (SeverancePayCalc): 입사일·퇴사일·평균임금 기준 법정 퇴직금 계산
  • BMI/칼로리 계산기 (BmiCalc): 키·체중 기준 BMI, 나이·성별·활동량 기준 기초대사량·활동대사량 계산

생활·재미

  • 로또 번호 생성기 (LottoGen): 1~45 중 6개 번호 무작위 생성. 당첨을 보장하지 않는 오락용 도구
  • 세탁 표시 기호 사전 (LaundrySymbolRef): 세탁 라벨 기호 검색·설명 조회

서비스의 주요 특징은 다음과 같습니다.

  • 모든 파일 처리는 이용자의 브라우저(클라이언트) 내에서만 이루어집니다.
  • 업로드된 파일은 외부 서버로 전송되지 않습니다.
  • 별도의 회원가입 없이 무료로 이용할 수 있습니다.

제3조 (약관의 효력 및 변경)

  • 본 약관은 서비스 화면에 게시함으로써 효력이 발생합니다.
  • 서비스는 필요한 경우 약관을 변경할 수 있으며, 변경된 약관은 본 페이지를 통해 공지합니다.
  • 변경된 약관에 동의하지 않는 경우 서비스 이용을 중단하실 수 있습니다.
  • 변경 공지 후 계속 서비스를 이용하시면 변경된 약관에 동의한 것으로 간주합니다.

제4조 (이용자의 의무)

이용자는 서비스를 이용함에 있어 다음 행위를 하여서는 안 됩니다.

  • 타인의 개인정보를 무단으로 수집·이용·유포하는 행위
  • 서비스의 정상적인 운영을 방해하는 행위
  • 서비스를 악의적·불법적 목적으로 이용하는 행위
  • 저작권 등 지식재산권을 침해하는 행위
  • 기타 관련 법령을 위반하는 행위

제5조 (서비스 이용)

  • 서비스는 24시간 연중무휴 제공을 원칙으로 합니다.
  • 단, 시스템 점검·장애·천재지변 등의 사유로 서비스가 일시 중단될 수 있습니다.
  • 서비스는 사전 공지 없이 서비스 내용을 변경하거나 종료할 수 있습니다.
  • 신규 도구 및 기능은 순차적으로 추가될 수 있습니다.

제6조 (처리 결과의 정확성)

BrowserKit의 자동 처리 기능(마스킹, 변환, 압축 등)은 처리 결과의 완전성을
100% 보장하지 않습니다.
중요한 문서는 반드시 직접 검수하시기 바랍니다.
  • 이미지 품질, 파일 형식, 복잡도 등에 따라 처리 결과가 달라질 수 있습니다.
  • 자동 처리 오류로 인한 피해에 대해 서비스는 법적 책임을 지지 않습니다.
  • 처리 결과물 사용 전 이용자가 직접 확인할 것을 권장합니다.

제7조 (지식재산권)

  • 서비스 내 모든 콘텐츠(디자인, 텍스트, 로고 등)의 지식재산권은 BrowserKit에 귀속됩니다.
  • 이용자가 업로드한 파일의 저작권은 이용자 본인에게 귀속됩니다.
  • 서비스는 이용자의 파일을 저장하거나 활용하지 않습니다.

제8조 (면책 조항)

서비스는 다음의 경우에 책임을 지지 않습니다.

  • 천재지변, 전쟁, 테러 등 불가항력적인 사유로 인한 서비스 중단
  • 이용자의 귀책 사유로 인한 서비스 이용 장애
  • 자동 처리 오류로 인한 피해
  • 제3자 서비스(Google AdSense, 쿠팡 파트너스 등)로 인해 발생한 문제
  • 이용자가 서비스를 통해 얻은 정보를 이용하여 발생한 손해

제9조 (광고 및 제휴)

서비스는 Google AdSense 및 쿠팡 파트너스를 통한 광고·제휴 링크를 게재할 수 있습니다. 광고 및 제휴 상품의 내용에 대한 책임은 해당 사업자에게 있으며, 서비스는 그 정확성을 보장하지 않습니다. 쿠팡 파트너스 링크를 통해 구매 시 일정 수수료가 서비스에 제공될 수 있습니다.

제10조 (준거법 및 관할)

  • 본 약관은 대한민국 법률에 따라 해석됩니다.
  • 서비스 이용과 관련한 분쟁이 발생한 경우 대한민국 법원을 관할 법원으로 합니다.
