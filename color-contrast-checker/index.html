색상 대비 검사기

사용법 가이드 보기

텍스트와 배경 색상의 명도 대비를 계산해 WCAG 접근성 기준 통과 여부를 확인해드려요

🔒 완전 로컬 처리 ⚡ 무료 사용 🛡️ 서버 전송 없음 📦 설치 불필요

💡 텍스트 색상과 배경 색상의 HEX 코드를 입력하면 WCAG 2.1 명도 대비(1:1~21:1)를 계산해 일반 텍스트·큰 텍스트 기준 AA·AAA 등급 통과 여부를 알려드립니다. 모든 계산은 브라우저에서만 이루어집니다.

사용법 요약

  1. 텍스트·배경 색상 입력(HEX 또는 색상 선택기)
  2. 명도 대비와 미리보기 자동 확인
  3. AA·AAA 등급 통과 여부 확인

자주 묻는 질문

WCAG AA·AAA는 무엇을 기준으로 하나요?

WCAG 2.1 기준으로 일반 텍스트는 AA 4.5:1 이상, AAA 7:1 이상, 큰 텍스트(18pt 이상 또는 14pt 굵게)는 AA 3:1 이상, AAA 4.5:1 이상을 통과 기준으로 봅니다.

색상 대비 검사기는 정말 무료인가요?

네, 회원가입이나 설치 없이 완전 무료로 사용할 수 있습니다. 검사 횟수 제한도 없습니다.

입력한 색상 정보가 서버로 전송되나요?

아니요. 모든 계산은 브라우저 안에서만 이루어지며 입력한 색상이 외부 서버로 전송되거나 저장되지 않습니다.

왜 접근성 기준을 지켜야 하나요?

대비가 낮은 텍스트는 저시력자·색약자뿐 아니라 야외에서 화면을 보는 일반 사용자에게도 읽기 어렵습니다. 공공기관·기업 웹사이트는 접근성 지침 준수가 요구되는 경우가 많습니다.
