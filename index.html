🔒 개인정보 보호 도구
🔒
개인정보 마스킹 (MaskPrivacy)
이미지 속 주민번호, 전화번호, 이메일, 계좌번호를 자동으로 탐지해 마스킹합니다.
✓ 서비스 중 📄
PDF 마스킹 (MaskPDF)
PDF 문서 속 개인정보를 브라우저에서 바로 마스킹합니다. 서버 전송 없이 안전하게 처리됩니다.
✓ 서비스 중 👤
얼굴 블러 (MaskFace)
이미지 속 얼굴을 자동으로 감지해 모자이크 처리합니다.
✓ 서비스 중 📝
텍스트 마스킹 (MaskDoc)
복사한 텍스트에서 주민번호, 전화번호, 이메일을 찾아 자동으로 가립니다.
✓ 서비스 중
🖼️ 이미지 편집 도구
🖼️
이미지 변환 (FitImage)
이미지 크기 조정, 형식 변환, 용량 압축을 브라우저에서 바로 처리합니다.
✓ 서비스 중 ✂️
이미지 자르기 (CropImage)
이미지 자르기, 회전, 반전을 브라우저에서 바로 처리합니다. 증명사진 / SNS 비율 단축 버튼 지원.
✓ 서비스 중 🏷️
워터마크 (WatermarkImage)
이미지에 텍스트 또는 로고 워터마크를 추가합니다. 투명도 및 위치 조절 지원.
✓ 서비스 중 🎨
색상 추출 (ColorPicker)
업로드한 이미지에서 HEX / RGB / HSL 팔레트를 추출합니다.
✓ 서비스 중 ✨
이미지 보정 (ImageBright)
밀기, 대비, 채도, 색온도를 슬라이더로 실시간 조절합니다. 6가지 빠른 프리셋으로 한 번에 보정.
✓ 서비스 중 ✂️
AI 배경 제거 (BGRemove)
AI가 이미지 배경을 자동으로 제거합니다. 투명 PNG로 저장하세요. 서버 전송 없이 브라우저에서 직접 처리.
✓ 서비스 중
📄 문서 / 텍스트 도구
📦
PDF 합치기 (PDFMerge)
여러 PDF를 하나로 합치거나 특정 페이지를 추출합니다. 모든 처리가 브라우저 내에서만 이루어집니다.
✓ 서비스 중 ⌨️
텍스트 변환 (TextTools)
글자수 세기, 줄바꾸 정리, 대소문자 변환, 중복 제거 등 텍스트 작업을 브라우저에서 바로 처리합니다.
✓ 서비스 중 🔄
텍스트 비교 (DiffChecker)
두 텍스트의 차이점을 줄 단위로 하이라이트합니다. 추가된 내용은 녹색, 삭제된 내용은 빨간색으로 표시합니다.
✓ 서비스 중 📝
마크다운 편집기 (MarkdownEditor)
마크다운을 입력하면 HTML 미리보기를 실시간으로 확인할 수 있습니다. HTML 저장 및 클립보드 복사 지원.
✓ 서비스 중 🔄
찾아 바꾸기 (FindReplace)
텍스트에서 단어를 찾아 일괄 치환합니다. 정규식 모드 지원, 개인정보 일괄 마스킹 프리셋 제공.
✓ 서비스 중
🔧 유틸리티 도구
📱
QR 코드 생성 (QRCode)
URL, 텍스트, 연락처를 QR 코드로 생성합니다. 크기와 색상을 설정하고 PNG로 다운로드할 수 있습니다.
✓ 서비스 중 🔐
비밀번호 생성기 (PasswordGen)
안전한 난수로 비밀번호를 생성합니다. 길이, 대소문자, 숫자, 특수문자 조합을 자유롭게 설정할 수 있습니다.
✓ 서비스 중 📐
단위 변환기 (UnitConvert)
길이, 무게, 온도, 넓이, 속도를 실시간으로 변환합니다. 입력하면 전체 단위 표가 한번에 표시됩니다.
✓ 서비스 중 📅
날짜 계산기 (DateCalc)
D-day 계산, 두 날짜 차이, 나이 계산을 한 번에. 만 나이와 한국 나이를 동시에 확인할 수 있습니다.
✓ 서비스 중 🌍
세계 시간 (WorldClock)
전 세계 도시 시간을 실시간으로 확인하고 시간대를 변환합니다. 해외 회의, 업무, 여행 필수 도구.
✓ 서비스 중
💻 개발자 도구
📦
JSON 포맷터 (JSONFormat)
JSON을 보기 쭐게 정렬하거나 압축합니다. 유효성 검사와 오류 위치 표시 기능을 지원합니다.
✓ 서비스 중 🔍
정규식 테스터 (RegexTest)
정규식을 입력하면 테스트 텍스트에서 매칭 영역을 실시간으로 하이라이트합니다.
✓ 서비스 중 🔠
Base64 변환 (Base64Tool)
텍스트 또는 이미지를 Base64로 인코딩하거나 디코딩합니다. data URI 형식으로 미리보기도 지원합니다.
✓ 서비스 중 🔑
해시 생성기 (HashGen)
텍스트와 파일의 MD5, SHA-1, SHA-256, SHA-512 해시값을 즉시 생성합니다. 파일 무결성 검증에 활용하세요.
✓ 서비스 중
📊 데이터 / 시각화 도구
📊
차트 생성기 (ChartMaker)
막대/선형/원형/도넛/레이더 차트를 즉시 생성합니다. CSV 업로드 지원, PNG/SVG로 저장.
